# HP・攻撃・守り・ダメージの数字を10倍にした（2026-11-25）

**状態：作った（2026-11-25）。**

細かく調整できるように、敵と主人公の「HP・攻撃・守り・ダメージ・回復」の数字を、まとめて10倍にした（ユーザーの要望）。
強さの釣り合いは、前と同じになるようにしている。

**この日より前に書いた仕様書の数字（HP 14 の敵、回復薬で15回復、など）は、10倍する前の大きさ。**

## 決まったこと（2026-11-25、ユーザーの選択）

| 項目 | 決めたこと |
|---|---|
| 10倍にする範囲 | **敵も主人公も**（敵の数字だけを10倍にすると、「攻撃 − 守り」の引き算で釣り合いが崩れるため） |
| 報酬 | **そのまま**（経験値・お金・店の値段・レベルアップに要る経験値は変えない） |

## 10倍にしたもの

| どこ | 項目 |
|---|---|
| 敵（`enemies.json`。テスト用・見本も） | HP・攻撃・防御（ボスも） |
| 武器・防具（`items.json`） | 武器の攻撃力・魔力、防具の守り・魔力 |
| ダンジョン（`dungeons/*.json`） | 入ったときのHP・最大HP、1レベルで増える最大HP・攻撃・魔力、魔法の強さ、癒しの回復量、再生の1ターンの回復量、衝撃波のぶつかったときの追加ダメージ |
| 状態異常（`statuses.json`） | 毒の毎ターンのダメージ、敵の燃焼の毎ターンのダメージ |
| 残響（`echoes.json`） | 数字がそのまま攻撃力・魔力になるもの（ただの残響 +10、ささやきの残響 +10、背水の残響 +30） |
| プログラムの数字 | 装備だけで組み立てたときの体力・攻撃・守り（600・60・10）、回復薬の回復量（150）、燃える床のダメージ（20）、満腹度0のときのダメージ（10） |
| 最低ダメージ | 「攻撃 − 守り」が小さいときに必ず入るダメージを、1から **10** にした（`COMBAT_CONFIG.minHit`）。指輪の耐性・弱点は、そのあとに掛かる |
| 管理画面 | 入力できる上限（敵のHP 99999・攻撃と防御 9999、武器と防具 9999、入ったときのHP 99999 など）と、説明の例文の数字 |

## 変えなかったもの

- 割合・倍率（体質や属性の相性、呪文の倍率、ダンジョンの強さの倍率、指輪の耐性%、残響の%の効果）。
- 魔力（呪文を唱えるのに使う量。MP）、満腹度、ターン数、マス数、確率。
- 経験値・お金・値段。

## 釣り合いの確かめ（10倍の前の main と比べた）

全部のダンジョン（1・3・5階目）× 全部の敵（通常・強敵）× 全部の武器・防具で、手数を数えて比べた。

| 手数 | 同じ | 差が1回以内 | 平均の比 |
|---|---|---|---|
| 武器で殴って倒すまで | 79% | 92% | ×1.015 |
| 炎の矢で倒すまで | 95% | 99% | ×1.006 |
| 敵に殴られて倒れるまで | 83% | 97% | ×1.041 |

変わったのは、前は小さな数字で四捨五入が大きく効いていたところ。たとえば、強敵の大ネズミの攻撃は、前は 3×1.5＝4.5 を 5 に切り上げてから倍率を掛けていたので、本来より強く出ていた。10倍にすると誤差が小さくなり、本来の値に近づく。

## 中断データ

中断データの版を 2 にした。それより前の中断データ（探索の途中で閉じたもの）は、数字の大きさが合わないので読まない（その探索はなかったことになる。倉庫・お金・思い出した記憶などのセーブは、そのまま）。
管理画面の書きかけの下書きは、元の設定が変わったので「古い下書き」として扱われる（今までの仕組みのまま）。
