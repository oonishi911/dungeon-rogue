# 残響の組み合わせ「共鳴」（2026-11-28）

武器のスロットに、決まった残響がそろうと、おまけの効果が付く。2026-11-23 に提案して保留にしていたものを、ここで決めた。

## きまり
- はめる順番は関係ない。同じ武器のスロットの中だけで決まる（別の武器の残響とは組み合わさない）
- 効くのは、いま手に持っている武器のスロットだけ。メインを持っているあいだはメインの共鳴、持ち替えたらサブの共鳴
- いくつ起きてもよい。数字は `src/game/resonance.ts` の `RESONANCE`（管理画面では変えない）
- 倉庫にある残響は、共鳴に関係しない（武器にはめたものだけ）

## 一覧
| 共鳴 | そろえるもの | 効果（初期の数字） |
|---|---|---|
| 三重奏 | 同じ残響 × 3 以上 | その残響の効果の合計が50%増える（四捨五入）。数字のない、炎・氷・光・闇の残響は変わらない |
| 蒸気 | 炎 ＋ 氷 | 通常攻撃のダメージ +15% |
| 日蝕 | 光 ＋ 闇 | 敵を倒すと、最大HPの5%が戻る（1より減らない） |
| 万象 | 柔らかい ＋ 硬い ＋ 霊体 | 体質を問わず、すべての敵へのダメージ +15% |
| 深い余韻 | 余韻 ＋ 追憶 | 余韻の追加ダメージが2倍 |
| 命綱 | 背水 ＋ 分け合い | HPが半分以下のとき、分け合いの回復が3倍 |
| 忍び足 | 不意 ＋ ひそやか | 不意打ちを決めた敵が、そのターン動けなくなる（ボスには効かない） |
| 満腹 | 満ち足り ＋ ぬくもり | 満ち足りで戻る満腹度が2倍 |

## 効き方のメモ
- 三重奏は、残響の数字を合計する場所（`echo.ts` の `total`）で足すので、攻撃力（ただの）・魔力（ささやき）・割合のダメージ・満腹度の軽減・技ゲージ・視界・お金・経験値・確率など、数字を持つ残響すべてに効く。上限（満腹度の軽減90%など）は、上乗せしたあとでも守る
- 蒸気・万象・深い余韻・命綱は、ダメージの計算に入れる。日蝕・満腹は、敵を倒したときの処理（呼ばれた敵とボスでは効かない）。忍び足は、通常攻撃のおまけと同じ場所
- 万象は、体質ごとのダメージの倍率（`bodyDamageRate`）に足す。柔らかい・硬い・霊体の残響を1つずつ持っていれば、その体質の敵には、残響の分と万象の分の両方が付く

## 画面
忘れ物屋の「刻印」の売り場で、
- 武器ごとに、起きている共鳴（緑）と、あと1つの残響で起きる共鳴（灰）を出す
- いちばん下の「共鳴の一覧」で、すべての組み合わせと効果を読める
