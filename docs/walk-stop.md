# 歩き続けているときに立ち止まる条件

2026-11-29：途中で勝手に立ち止まる仕組みは、すべてやめた（敵が見えた・攻撃を受けた・宝箱を見つけた、のどれでも止まらない）。

| 歩き方 | 止まるとき |
|---|---|
| 方向キーの押しっぱなし | キーを離したとき |
| 画面をなぞる | 指を離したとき |
| マスをタップ・クリック | 着いたとき・進めないとき・別の操作をしたとき。途中の敵に当たったら、倒すまで攻撃してから、また歩く |
| 敵をタップ | その敵が見えなくなったとき（倒したときも） |
| 「階段へ」 | 階段に着いたとき・もう一度押したとき・別の操作をしたとき |

- 階段を踏むと、そのまま階を移る（歩くのはそこで終わる）

- 2026-11-29：攻撃・宝箱でも止まらないようにし、`walkInterrupt` を消した。タップ歩きで敵に当たっても止まらない
