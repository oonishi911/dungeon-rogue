## 防具

- 属性ごとのマントと衣（耐火・耐氷のマント、光の衣、闇の衣）はやめる。防具は**1系統の鎧**（10段階）にして、性能は「守り」だけにする。
- 今の守りの数字を引き継ぐ（鎧の守り）。マントや衣の「カット率」で防いでいた分は、指輪が担う。
- 昔の記録に、マントや衣があるとき：同じ段階の鎧に変えて持ち越す。あわせて、そのマントや衣の属性の、同じ段階の指輪をもらう（買ったものが無駄にならないように）。

## 指輪

- **装備枠**：「指輪」の枠。付けられる数は、思い出した記憶の数で増える（0〜1個で1つ、2〜3個で2つ、4個以上で3つ）。
- **同じ指輪は1つだけ**付けられる（同じ属性の指輪を重ねるのは、なし）。ちがう指輪は、効果が**掛け算**（炎の指輪30%と光の指輪20%なら、炎の攻撃は0.7、光の攻撃は0.8。複数の属性に当てはまる攻撃は、それぞれの耐性が掛かる）。
- **逆の属性に弱くなる**：属性の指輪は、耐性が付く代わりに、逆の属性の攻撃のダメージが増える。増える割合は、その指輪の耐性の**半分**（初期。管理画面で変えられる）。
  - 炎の指輪 ⇄ 氷の指輪、光の指輪 ⇄ 闇の指輪が、逆の関係。
  - 無属性の指輪・万能の指輪・二重耐性の指輪には、弱点はない（そのぶん、無属性は効く範囲が狭く、万能は耐性が小さく、二重耐性は買えない）。
  - 例：炎の指輪3段（炎の攻撃を30%減らす）を付けると、氷の攻撃のダメージが15%増える。炎の指輪と氷の指輪を両方付けると、炎の攻撃は0.7×1.15、氷の攻撃は0.7×1.15 になる（どちらにも耐性が付くが、少し弱点も出る）。
- **属性の数え方**：今のダメージ計算と同じ。光は「炎＋無属性」、闇は「氷＋無属性」を半分ずつ。炎の指輪は光の攻撃の炎の半分に、無属性の指輪は光・闇の攻撃の無属性の半分に効く。光の指輪・闇の指輪は、その属性の攻撃を丸ごと軽くする（今の光の衣・闇の衣と同じ）。

| 指輪 | 効く攻撃 | 弱点（逆の属性） | 段階ごとの耐性（初期の数字） |
|---|---|---|---|
| 炎の指輪 | 炎（光の炎の半分） | 氷（闇の氷の半分） | 1段10% → 2段20% → 3段30% → 4段40% → 5段50% |
| 氷の指輪 | 氷（闇の氷の半分） | 炎（光の炎の半分） | 同じ |
| 無属性の指輪 | 無属性（光・闇の無属性の半分） | なし | 同じ |
| 光の指輪 | 光 | 闇 | 同じ |
| 闇の指輪 | 闇 | 光 | 同じ |
| 万能の指輪 | すべての属性 | なし | 1段5% → 2段10% → 3段15% → 4段20% → 5段25%（値段は高い） |

- **店に並ぶ段階**：武器と同じ決まり（持っている種類のいちばん上の段階の2つ上まで。持っていなければ2段目まで）。
- **値段**（仮）：1段 60、2段 150、3段 320、4段 600、5段 1000。万能の指輪は、同じ段階の2倍。
- **二重耐性の指輪**（買えない）：2つの属性に、同時に耐性が付く（例：炎と氷の指輪）。敵がごく稀に落とす。倒した敵の属性と、もう1つの属性（くじ）の組み合わせ。耐性は、それぞれ20〜40%（落とすときに、段階をくじで決める）。確率は、初期は 通常の敵0.3%・強敵3%・ボス10%。同じ組み合わせは1つだけ付けられる。
- **力尽きても失わない**（残響と同じ）。拾った二重耐性の指輪は、倉庫に入る。
- **付け替え**：忘れ物屋の「指輪」の売り場（買う・装備する）。探索中は付け替えられない。

## 情報屋との関係

- 情報屋から、ダンジョンの属性かボスの属性を**はっきり**聞くと、その属性の指輪（と、その属性を含む二重耐性の指輪）に「おすすめ」の印が付く。
- 属性を聞けていないとき（うわさだけのときも）は、万能の指輪に「おすすめ」の印が付く（弱点がないので、保険になる）。
- 逆の属性に弱くなるので、属性の指輪は「当たりを引けば強く、外すと少し痛い」。情報を聞く意味が、さらに強まる。

## 管理画面

- 品物の設定に、指輪（5種類×5段階の名前・耐性・値段、万能の指輪）を足す。弱点の割合（耐性の何%か。初期は50%）も、ここで変えられる。
- 残響のタブに並べて、「指輪」の設定に、指の数の記憶の数、二重耐性の指輪を落とす確率・耐性の範囲を足す。
