# 戦闘の拡張（2026-11-16 に仕様を決定）

敵の行動の個性・属性反応と床・武器の固有技・ボスの3段階変化と、それに合わせた見た目の仕様。
実装は別々のプルリクエストで進める。各項目の状態は末尾の「進み具合」に書く。

## 1. 敵の行動の個性（実装済み。`src/game/enemyBehavior.ts`、`explore.ts` の `enemiesTurn`）

敵のデータの `behaviors` に、次の4つを重ねて付けられる（管理画面の「敵」タブの「個性」欄）。省略すると、これまでどおりの動き。
個性の動きをするのは、**主人公を追っていて、主人公が見えているあいだ**だけ。数値は `ENEMY_CONFIG`（`src/game/enemies.ts`）。

| 個性 | 動き |
|---|---|
| 遠距離 `ranged` | 主人公とまっすぐ（縦か横）で、間に壁も敵もなく、2〜4マス離れていれば、動かずに撃つ。ダメージは通常の0.8倍（`rangedRate`）。隣り合うと、撃てる位置へ1歩下がる（下がったあと2ターンは下がらず、近づかれたら殴る。いつまでも逃げ続けて決着がつかなくなるのを防ぐ） |
| 突進 `charger` | まっすぐ2〜3マス離れていると、1ターン構える（頭上に赤い「‼」）。次のターンに、その向きへ最大5マス走る（主人公が動いていても同じ向き）。当たれば通常の1.5倍。避けられて壁にぶつかると、自分が1ターン動けない。走ったあと2ターンは構えない。構えている間に気絶させられると、構えは解ける |
| 盾持ち `shield` | 向いている正面（向き＝最後に歩いた向き）からの武器の攻撃を、7割カットする（`shieldCut`）。背中・側面・呪文は通常どおり。盾の板が正面に見え、体もその向きを向く |
| 召喚 `summoner` | 5ターンごとに、隣のあいている床へ、その属性の道中でいちばん弱い敵（HP×攻撃が最小）を呼ぶ。同時に出していられるのは2体まで。呼ばれた敵は、倒しても報酬（金貨・経験値・道具）も倒した数もない |

- 呪術師は遠距離＋召喚。召喚したターンは、ほかのことはしない
- 気付いた最初のターンは動かない・気絶中は何もしない、は今までどおり
- 画面：矢が飛ぶ（体質ごとの色）、盾に防がれた数字は青灰色、壁にぶつかると「★」、召喚すると「呼」が浮かぶ

## 2. 属性反応と床（未実装。見た目の「魔法の跡」と一体）

- **燃える床**：3ターン。乗ると毎ターン2ダメージ。炎の呪文が当たった敵の足元に生まれる（炎の連矢は周りにも）。炎の砥石で攻撃したときも生まれる
- **霜の床**：4ターン。乗ると次の1歩に2ターンかかる。氷の呪文・氷の砥石で生まれる
- 燃える床と霜の床が隣り合うと、両方消えて水蒸気になる
- 炎の敵は燃える床で、氷の敵は霜の床で、影響を受けない
- **主人公にも敵にも効く**
- 光・闇の床は今回は作らない

## 3. 武器の固有技（未実装）

- 技ゲージ：通常攻撃を当てるたびに+1。満タンで「技」を出せる（1ターン使い、ゲージは0に戻る）
- 満タンまでの回数は武器の段階で変わる：1〜3段は4回、4〜7段は3回、8〜10段は2回
- 剣「連斬り」：向いた方向の敵に2回、合計で通常の1.6倍。出血付き
- 槌「地響き」：周囲8マスの敵全員に、通常ダメージ＋1ターン気絶
- 杖「魔力弾」：向いた方向の最初の敵に、魔法の強さ×1.5。防御は無視。杖の倍率は使う
- 専用のボタンで出す

## 4. ボスの3段階変化（未実装。1と2のあとに作る）

- 5体（炎の魔獣・氷の巨像・鬼の首領・光の守護者・闇の王）が対象
- 体力が2/3と1/3を切るたびに、段階が上がる。上がるときは1ターン咆哮して攻撃しない。攻撃力は段階ごとに+25%
- 新しい行動（段階2 / 段階3）：炎の魔獣＝燃える床をまく / 突進、氷の巨像＝霜の床 / 盾持ち、鬼の首領＝手下を呼ぶ / 突進、光の守護者＝盾持ち / 遠距離、闇の王＝手下を呼ぶ / 遠距離
- 模型も段階で変わる

## バランスの注意

敵の個性は、同じ数値の敵を強くする。標準のダンジョンの自動プレイ（`npm run test:balance`）で、炎・光のクリア率が下がったため、
自動プレイの動きに「撃ってくる敵は先に倒しに行く」を足し、テスト用データ（`src/game/testdata/enemies.json`）の個性のある敵の攻撃を下げた。
実際の敵のデータ（`src/game/enemies.json`）の数値は、まだ調整していない。遊んでみて、管理画面の「敵」タブで調整する。
