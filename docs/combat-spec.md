# 戦闘の拡張（2026-11-16 に仕様を決定）

敵の行動の個性・属性反応と床・武器の固有技・ボスの3段階変化と、それに合わせた見た目の仕様。
実装は別々のプルリクエストで進める。各項目の状態は末尾の「進み具合」に書く。

## 1. 敵の行動の個性（実装済み。`src/game/enemyBehavior.ts`、`explore.ts` の `enemiesTurn`）

敵のデータの `behaviors` に、次の個性（動きの4つと、炎の足跡・待ち伏せと、状態異常の毒・鈍足・空腹）を重ねて付けられる（管理画面の「敵」タブの「個性」欄）。省略すると、これまでどおりの動き。
個性の動きをするのは、**主人公を追っていて、主人公が見えているあいだ**だけ。数値は `ENEMY_CONFIG`（`src/game/enemies.ts`）。

| 個性 | 動き |
|---|---|
| 遠距離 `ranged` | 主人公とまっすぐ（縦か横）で、間に壁も敵もなく、2〜4マス離れていれば、動かずに撃つ。ダメージは通常の0.8倍（`rangedRate`）。隣り合うと、撃てる位置へ1歩下がる（下がったあと2ターンは下がらず、近づかれたら殴る。いつまでも逃げ続けて決着がつかなくなるのを防ぐ） |
| 突進 `charger` | まっすぐ2〜3マス離れていると、1ターン構える（頭上に赤い「‼」）。次のターンに、その向きへ最大5マス走る（主人公が動いていても同じ向き）。当たれば通常の1.5倍。避けられて壁にぶつかると、自分が1ターン動けない。走ったあと2ターンは構えない。構えている間に気絶させられると、構えは解ける |
| 盾持ち `shield` | 向いている正面（向き＝最後に歩いた向き）からの武器の攻撃を、7割カットする（`shieldCut`）。背中・側面・呪文は通常どおり。盾の板が正面に見え、体もその向きを向く |
| 召喚 `summoner` | 5ターンごとに、隣のあいている床へ、その属性の道中でいちばん弱い敵（HP×攻撃が最小）を呼ぶ。同時に出していられるのは2体まで。呼ばれた敵は、倒しても報酬（金貨・経験値・道具）も倒した数もない |

- 炎の足跡 `trail`（2026-11-20）：歩くたびに、離れたマスに**燃える床**（3ターン。「2. 属性反応と床」と同じもの）を残す。炎の敵は燃えず、主人公とほかの敵は、乗るとターンの終わりに2ダメージ。霜の床と隣り合うと、水蒸気になって消える（氷の砥石・氷の呪文が答え）。気付かれていないうろつきでも残す。主人公のいるマスには置かない。炎の指輪は、床のダメージには効かない（敵の攻撃だけに効く）
- 待ち伏せ `ambush`（2026-11-20）：**気付かれていないあいだ**は、その場から動かず（うろつかない）、気付く範囲も2マス（`ambushRange`。ふつうは視界5マス）。2マス以内に近づかれると、**気付いたターンの猶予なしで**そのターンに動く（隣なら殴る）。頭上に「！」と、記録に「〜が襲いかかってきた」。遠くから呪文を撃てば、不意打ち（2倍）になる。一度気付いたら、ふつうの敵と同じに追う（見失ってうろつきに戻ると、その場でまた待つ）
- 見張り `alarm`（2026-11-21。光の鳥・闇コウモリ）：主人公に**自分の手番で気付いた**とき、叫んで、縦横斜め5マス以内（`alarmRange`。壁ごしでも届く）の、まだ追っていない仲間を、近い順に3体まで（`alarmMax`）一斉に気付かせる。気付かされた仲間は、そのターンは身構えるだけで、次のターンから、叫ばれたときに主人公がいた所へ向かう（見えなければ、ふつうに探して、5ターンであきらめる）。ボス・動けない敵には届かない。合図は連鎖しない（気付かされた見張りは叫ばない）。叫んだ見張り本人も、気付いたターンは動かない。頭上に「叫」と、声の届く広さまで広がる橙の輪、記録に「〜が叫んで、仲間を呼んだ」。**答え**：気付かれる前に倒す（遠くから呪文）、不意打ちで先に殴る（殴られて気付いた見張りは叫ばない）、見張りの視界（5マス）に入らない
- 毒 `poison`・鈍足 `chill`・空腹 `hunger`：攻撃が当たると、確率で状態異常にかかる。上の4つとはちがい、動きは変えない（いつもの攻撃に付く）。くわしくは `docs/status-spec.md`
- 呪術師は遠距離＋召喚。召喚したターンは、ほかのことはしない
- 気付いた最初のターンは動かない・気絶中は何もしない、は今までどおり
- 画面：矢が飛ぶ（体質ごとの色）、盾に防がれた数字は青灰色、壁にぶつかると「★」、召喚すると「呼」が浮かぶ、見張りが叫ぶと「叫」と橙の輪

## 2. 属性反応と床（実装済み。`src/game/fields.ts`、`explore.ts` の `fieldsTurn`・`passTurn`）

床に残る魔法の跡は、探索の状態の `fields`（位置・種類・残りターン）で持つ。数値は `FIELD_CONFIG`（`fields.ts`）。

| 床 | 残るターン | 乗っていると |
|---|---|---|
| 燃える床 | 3 | ターンの終わりに、毎ターン2ダメージ（主人公にも敵にも）。燃える床で倒れた敵は、ふつうに倒したときと同じ報酬 |
| 霜の床 | 4 | 次の1歩に2ターンかかる（主人公は、霜の床から歩き出すと、その1歩に2ターン。敵は、霜の床の上から歩き出すとき、1ターン余計に動けない）。殴る・殴られるのは1ターンのまま |

- **床が残るとき**：炎の矢・炎の連矢が当たった敵の足元に燃える床、氷の矢・氷の連矢なら霜の床。連矢は、当たった敵のまわり8マスにも残す。炎の砥石・氷の砥石の武器で敵を殴ったときも、その敵の足元に残る。光・闇の呪文は残さない（光・闇の床は今回は作らない）。何にも当たらなければ残らない
- 壁と主人公のいるマスには残さない。同じ床にもう一度残ると、残りターンが延びる
- **水蒸気**：燃える床と霜の床が、同じマスか縦横に隣り合うと、両方消えて水蒸気になる（斜めなら消えない）
- **影響を受けない敵**：炎の属性の敵は燃える床に、氷の属性の敵は霜の床に、影響を受けない（光は炎＋無属性、闇は氷＋無属性なので、影響を受ける）
- 階を移ると、床の跡は消える。中断データにも保存しない（数ターンで消えるため）
- 画面：燃える床はちらつくオレンジの炎、霜の床は青白い氷の結晶。最後の1ターンは薄くなる。水蒸気は白い粒が立ち上る（「動きを減らす」設定では、ちらつきと水蒸気を出さない）

## 3. 武器の固有技（実装済み。`src/game/weaponSkill.ts`、`explore.ts` の `useSkill`）

- **技ゲージ**：通常攻撃（敵に体当たり）を当てるたびに+1。満タンになると技を出せる（1ターン使い、ゲージは0に戻る）。武器を持っていない（素手の）ときは技もゲージもない。ゲージは探索の状態の `skill`（階を移っても残る。中断データにも保存）
- **満タンまでの回数**は武器の段階で決まる：1〜3段は4回、4〜7段は3回、8〜10段は2回（`SKILL_CONFIG.gauge`）
- **向き**：剣と杖の技は、主人公が向いている方向（最後に歩こうとした向き）に出す。敵に当たらないときは出せず、ゲージも減らない

| 武器 | 技 | 効果 |
|---|---|---|
| 剣 | 連斬り | 向いた方向の隣の敵に2回、合計で通常の1.6倍。倒れなかった敵は3ターン出血する（毎ターン、1回のダメージの2割。出したターンはまだ受けない） |
| 槌 | 地響き | まわり8マスの敵すべてに、通常のダメージと1ターンの気絶。向きは要らない |
| 杖 | 魔力弾 | 向いた方向の5マス先までの最初の敵に、魔法の強さ×1.5のダメージ。敵の防御は無視。杖の倍率は使う。盾では防がれない |

- 剣と槌は武器の攻撃なので、盾持ちの正面からは7割防がれる。属性を宿した武器（砥石）なら、剣と槌の技でも属性の力を1回使い、炎・氷なら当たった敵の足元に床が残る（槌は当たった敵すべて）。通常攻撃のように、敵の属性との相性も効く
- 操作：右の列の技のボタン（丸が技ゲージ。満タンで光る）か、**f キー**
- 画面：剣は斬撃の残光が2回、槌は足元から広がる輪、杖は紫の魔力の玉が飛ぶ。連斬りの2つの数字は少しずらして出る

## 4. ボスの3段階変化（実装済み。`src/game/bossPhase.ts`、`explore.ts` の `phaseUp`・`sowFields`・`enemiesTurn`）

- 5体（炎の魔獣・氷の巨像・鬼の首領・光の守護者・闇の王）が対象
- 体力が 2/3 と 1/3 以下になるたびに、段階（1〜3）が上がる。一度上がった段階は下がらない。上がるときは、そのターンは咆哮して攻撃も移動もしない（動けない状態を1ターン入れる）。強い一撃で一気に第3段階になっても、咆哮は1回
- 攻撃力は段階ごとに+25%（第2段階 ×1.25、第3段階 ×1.5。`BOSS_CONFIG.atkStep`）。HP・防御はそのまま
- 新しい行動（段階2 / 段階3。前の段階の行動は続く）：

| ボス | 段階2 | 段階3 |
|---|---|---|
| 炎の魔獣 | 燃える床をまく | 突進 |
| 氷の巨像 | 霜の床をまく | 盾持ち |
| 鬼の首領 | 手下を呼ぶ | 突進 |
| 光の守護者 | 盾持ち | 遠距離 |
| 闇の王 | 手下を呼ぶ | 遠距離 |

- 突進・盾持ち・遠距離・召喚は、1の「敵の行動の個性」と同じ決まりで動く（`enemyDef` が、段階までの個性を足した能力を返す）
- 床まき：主人公が見えているあいだ、4ターンごと（`BOSS_CONFIG.sowEvery`）に、そのターンの行動のかわりに、主人公のまわり（縦横2マス以内。主人公のいるマスは除く）の5マスに、燃える床・霜の床をまく。床の決まりは2と同じ（炎の魔獣は燃える床、氷の巨像は霜の床に影響されない）
- 段階ごとの行動は、コード（`PHASE_RULES`）で決める。敵のマスターや管理画面の「敵」の表からは変えられない
- 見た目：段階が上がると、体が少し大きくなり（+8%）、足元の輪が金→橙→赤に変わって大きくなる。咆哮のときは、足元から輪が広がって画面が揺れ、「咆」の文字が出る。床まきは、ボスから玉が飛んで床になる。盾は、持つ段階になってから表示する。
  模型そのものを段階ごとに作り替えること（角が生える、など）はしていない（ボスの模型は部品を組む作りで、段階ごとの専用部品は手間が大きいため）
- 保存：段階（`MapEnemy.phase`）は、中断データにも入る

## 5. 見た目（実装済み。3は2と一体で、先に実装済み）

数値は `src/ui/explore3dConfig.ts`（`DEATH_FX`・`GLOW_FX`・`INTRO_FX`・`AFTERGLOW_FX`）。どれも「動きを減らす」設定では、動きを止めるか省く。

1. **敵ごとの倒れ方**（`src/game/deathKind.ts`の`deathKindOf`が種類を決め、`explore3d.ts`の`updateCollapses`が動かす）
   - 氷の敵：一瞬ふくらんで砕け、氷の破片が飛び散る
   - 霊体の敵：細く伸びながら昇って消え、紫の霧が立ちのぼる
   - スライム（IDに`slime`を含む。氷のスライムは氷が先）：大きくふくらんで弾け、しずくが飛ぶ
   - 硬い敵（上のどれでもないとき）：つぶれて傾きながら崩れ、かけらが落ちる
   - それ以外：今までどおり、つぶれて倒れる
2. **武器の斬撃の残光**（通常攻撃に付く。固有技は固有技の演出があるので付けない）：武器の段階で派手になる。1〜3段は細い白青の1本、4〜7段は金色の2本、8〜10段は橙の3本と火花。槌と杖は、衝撃の光と火花（色と数が段階で増える）
3. 魔法の跡が床に残る（「2. 属性反応と床」と一体。実装済み）
4. **敵が自分で光る**：炎・光・闇・氷の敵は、足元に光が広がる（炎は橙で大きくちらつく、光は薄い黄、闇は紫、氷は薄い青。強敵・ボスは1.35倍）。光は敵が見えているあいだだけ出る。ゲームのルールには関係しない（暗がりでも敵の位置が分かりやすくなるが、見えない敵は光も見えない）
5. **強敵とボスの登場演出**：初めて視界に入ったとき、カメラが少し寄って（1.2倍）戻り、画面の上に名前（「強敵」「ボス」の札つき）が出る。ボスは長めに出す。操作は止めない。中断から再開したときは、見えている強敵・ボスにもう一度出る

## バランスの注意

ボスの3段階で、ボス戦のダメージが増えた。テスト用データの光の守護者の攻撃を14から11に下げて、自動プレイのクリア率を基準（0.8以上）に戻した。**本物の敵データ（`src/game/enemies.json`）のボスの数値は調整していない**。

敵の個性は、同じ数値の敵を強くする。標準のダンジョンの自動プレイ（`npm run test:balance`）で、炎・光のクリア率が下がったため、
自動プレイの動きに「撃ってくる敵は先に倒しに行く」を足し、テスト用データ（`src/game/testdata/enemies.json`）の個性のある敵の攻撃を下げた。
実際の敵のデータ（`src/game/enemies.json`）の数値は、まだ調整していない。遊んでみて、管理画面の「敵」タブで調整する。

### 2026-11-20：炎の足跡・待ち伏せと、個性のなかった敵への割り当て
個性のなかった通常の敵8体に個性を付けたあと、深い祠（a_2）の「正しい準備」（自動プレイ、各属性300回）は **約52%**（炎45・氷45・無54・光62・闇55。外れた準備10%・準備なし15%）で、目標の約50%の範囲内。a_2 の設定は変えていない。
自動プレイは、燃える床をよけない・待ち伏せの敵を遠くから撃たない（近づくので、毎回襲われる）。遊ぶ人はこれより有利。

### 2026-11-20：武器の持ち替え
自動プレイの準備（`bestLoadout`）はサブ武器を持たないので、a_2 の計測は変わらない（正しい準備 約52%・外れた準備 10%・準備なし 15%）。サブ武器の強さは、実際に遊んで確かめる（サブ1つで道具が1つ減る代わりに、相性の悪い敵への手段が増える）。

### 2026-11-20：敵への燃焼・凍結とコンボ
自動プレイは炎・氷の呪文と砥石を使わないので、a_2 の計測は変わらない（正しい準備 約52%・外れた準備 10%・準備なし 15%）。燃焼・凍結・コンボの強さは、実際に遊んで確かめる。数字は管理画面の「状態異常」タブで変えられる。
