# 設定の画面

探索の画面の上の歯車（設定）と、ダンジョンを選ぶ画面の「設定」から開く（`src/ui/SettingsDialog.tsx`）。
変えた設定はブラウザに保存し、次に遊ぶときも同じにする。

| まとまり | 項目 | ふだん |
| --- | --- | --- |
| 音 | 音を鳴らす・効果音の大きさ・環境音の大きさ | あり・70%・60% |
| 演出 | 画面の揺れ・ヒットストップ | あり・あり |
| 表示 | 文字の大きさ（小 90%・中・大 115%） | 中 |
| 表示 | 敵の頭上の弱点の印 | あり |
| キーの割り当て | 歩く（上下左右）・待つ・呪文1〜5・武器の技・持ち替え・階段へ | W A S D・Space・Z X C V B・F・Q・G |

- 音は `dungeon-prep/sound`（src/storage.ts・audio/settings.ts）、それ以外は `dungeon-rogue:feel`（`src/ui/feelSettings.ts`）に保存する。前の形（揺れとヒットストップだけ）の保存も読める
- 文字の大きさは、ページの基準の文字の大きさ（html の font-size）を変える。画面の大きさはほとんど rem で決めているので、全体が同じ割合で大きくなる
- キーの割り当て（`src/ui/keyBindings.ts`）
  - 「変える」を押してから使いたいキーを押す。Esc でやめる
  - ほかの操作が使っているキーにすると、入れ替わる
  - 矢印キー（歩く）・「.」（待つ）・1〜9（道具）・Enter と Esc（呪文を唱える・やめる）は決まった働きなので、割り当てられない。矢印キーと「.」は、割り当てを変えてもいつでも使える
  - ボタンのキーの印・操作の説明・待機と「階段へ」のボタンも、割り当てのとおりに出す
  - 指で遊ぶ端末では、キーの割り当ては出さない
- 弱点の印を切ると、すぐ消える。つけ直したときは、次の手から出る
