# 画質の設定（2026-11-29）

設定の画面の「表示」→「画質」で、3D 画面の画質を「軽い／ふつう／きれい」から選ぶ（ふだんは「ふつう」）。選ぶとすぐ反映し、ブラウザに保存する（`feelSettings.ts` の `graphics`）。

| 画質 | 中身 |
|---|---|
| 軽い | 解像度1倍（端末の細かさを使わない）・地面の霧・空気の粒・画面の仕上げ（光のにじみなど）なし・影の地図 256。さらに、1秒に30コマまでしか描かない（電池と熱のため。歩く・戦う処理は毎コマ進める） |
| ふつう | これまでと同じ。端末の速さに合わせて、6段のあいだを自動で上げ下げする（遅いコマがたまったら1段下げ、余裕が続いたら1段上げる） |
| きれい | いちばん上の段に固定：解像度は端末の細かさ（3倍まで）・霧・粒・仕上げあり・影の地図 2048（ふつうの最高は 1024）。処理の弱い端末でも霧と仕上げを使う。下げないので、重い端末ではカクつくことがある |

- 段の一覧は `src/ui/explore3dConfig.ts` の `QUALITY.levels`（0：きれい、1〜6：ふつう、7：軽い）。どの段を使ってよいかは `src/ui/graphicsQuality.ts`
- 開発用の `?quality=番号` を付けると、設定によらず、その段に固定する（これまでどおり）
- テスト：`graphicsQuality.test.ts`・`feelSettings.test.ts`
