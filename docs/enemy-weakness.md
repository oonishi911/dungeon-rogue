# 敵の弱点の表示と、敵の図鑑（2026-11-23）

敵の弱点（効く武器・効く属性）を、いつでもわかるようにする。

## 決まったこと（2026-11-23、ユーザーの選択）

| 項目 | 決めたこと |
|---|---|
| いつわかるか | **最初からいつでも**（当てる前から、どの敵でも） |
| どこに出すか | **敵の頭上**と、**敵の図鑑** |

## 弱点の決め方（`src/game/weakness.ts`）

相性の数字は、今の戦闘の計算と同じもの（`data.ts`）。

- **効く武器**：武器と体質の相性（`WEAPON_VS_BODY`）が1倍より大きい武器。柔らかい→剣、硬い→槌、霊体→杖（どれも1.5倍）。普通の体は、なし。
- **効く属性**：攻撃に乗せた属性と、敵の属性の相性（`ENCHANT_VS_ELEMENT`）が1倍より大きい属性。炎の敵→氷（2倍）、氷の敵→炎（2倍）、光の敵→闇（2倍）、闇の敵→光（2倍）・炎（1.5倍）など。
- **魔法・物理**：敵の設定の `magic`・`physical`（呪文・武器で受けるダメージの倍率）が1より大きければ、その弱点。
- 1倍より小さいものは「効きにくい」。

## 敵の頭上の印

- 見えている敵の頭上に、暗い札を浮かべる。左から、小さな「弱」の見出し、いちばん効く武器（剣・槌・杖）、いちばん効く属性（炎・氷・光・闇。属性の色）、魔法に弱ければ「魔」（物理に弱ければ「物」）。
- 弱点がない敵（普通の体・無属性で、魔法・物理の倍率も1以下）には出さない。
- 状態の印（気付いた「！」・燃焼・凍結など）は、これまでどおり、その下に出る。
- 大きさ・高さ・色は `src/ui/explore3dConfig.ts` の `WEAK_MARK`。

## 敵の図鑑（`src/game/bestiary.ts`、`src/ui/BestiaryScreen.tsx`）

- ダンジョンを選ぶ画面の「敵の図鑑」から開く。
- 載るのは、どれかのダンジョンに出る敵（道中の敵とボス）。炎・氷・光・闇・無属性の魔物と、最深部の主（ボス）のタブに分ける。
- **出会ったことのある敵**（探索で見えた敵）は、属性・体質・行動の個性・強さ（HP・攻撃・守り。ダンジョンや深さで上がる前の数字）・よく効くもの・効きにくいもの（倍率つき）がわかる。まだ出会っていない敵は「？？？」。
- 出会った敵は、探索のあいだ `ExploreState.found.met` に入り、終わったとき（力尽きても、リタイアしても）セーブの `met` に入る。昔の記録・中断データは、空から始める。

## まだ決めていないこと

- 近くの敵の一覧（探索画面の横）にも、弱点の印を付けるか。
- 頭上の印を消す設定（画面がうるさいと感じたとき）。
