# 3D表示のテクスチャの仕様

3D表示の床と壁に貼る画像。ダンジョン特性ごとに見た目を変える。
今は `scripts/build-textures.ts` で作った仮の素材が入っている。同じ配置で描いたPNGに差し替えれば、そのまま画面に反映される。

## ファイル

| 特性 | ファイル |
|---|---|
| 炎 | `public/textures/fire.png` |
| 氷 | `public/textures/ice.png` |
| 無属性 | `public/textures/neutral.png` |
| 光 | `public/textures/light.png` |
| 闇 | `public/textures/dark.png` |

- PNG、**128×64px**、1マス32×32px。
- ドット絵として描く。画面ではぼかさずに拡大する（ぼかしや半透明の縁は使わない）。
- 読み込めなかったときは、特性ごとの色で描く。

## 配置

```
 x:  0      32      64      96     128
y:0 ┌───────┬───────┬───────┬───────┐
    │ 床1   │ 床2   │ 床3   │ 床4   │
 32 ├───────┼───────┼───────┼───────┤
    │壁の上面│壁の側面│（空き）│（空き）│
 64 └───────┴───────┴───────┴───────┘
```

### 床1〜4
- マスの位置で決まった1枚が使われる（同じ場所はいつも同じ模様）。1種類で足りるなら、4枚とも同じ絵でよい。
- 床は真上から見た絵として描く。画面ではカメラが斜め上（約63度）から見下ろすので、少し縦に縮んで見える。

### 壁の上面
- 壁（箱）の上の面。真上から見た絵として描く。
- 隣の壁と並ぶので、**上下左右の端で模様がつながるように描く**と、ひと続きの壁に見える。端に縁取りを描くと、ブロックを並べたように見える（今の仮の素材はこちら）。

### 壁の側面
- 壁（箱）の横の面。4方向とも同じ絵が使われる。
- 壁の高さはマスと同じ（1倍）なので、**32px全体が使われる**。
- 左右の端で模様がつながるように描くと、横に並んだ壁が続いて見える。

## 色と明るさについて
- 画面では、テクスチャに明るさを掛けて描く。今見えているマスはそのまま、一度見たが今は見えていないマスは暗く（30%）なる。
- 壁の側面は、上面より暗く描かれる（向きによって70〜85%）。主人公の周りは、たいまつの灯りで少し明るくなる。

## 確かめ方

```bash
npm run dev
```

`http://localhost:5173/?view=explore&trait=fire` のように特性を指定して開くと、そのテクスチャで探索画面を確かめられる（`&seed=1` で同じ階層、`&rank=3` で広さを指定）。
