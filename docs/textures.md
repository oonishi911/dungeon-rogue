# 3D表示のテクスチャの仕様

3D表示の床と壁に貼る画像。ダンジョン特性ごとに見た目を変える。
氷は、AIで作ったシームレスな氷の画像（`assets/texture-sources/ice.jpg`）から作った素材。ほかの特性は、`scripts/build-textures.ts` で作った仮の素材が入っている。
同じ名前のPNGに差し替えれば、そのまま画面に反映される（大きさはコードでは決めていない）。

## ファイル

特性ごとのフォルダに、6枚の画像を置く。

```
public/textures/
  fire/      炎
  ice/       氷
  neutral/   無属性
  light/     光
  dark/      闇
    floor1.png 〜 floor4.png   床（4種類）
    wall-top.png               壁の上面
    wall-side.png              壁の側面
```

- PNG、1枚が1マス分。仮の素材は **128×128px**、画像から作った素材は写真の細かい模様を生かすため **256×256px**。
- **なめらかな質感**として描く（ドット絵ではない）。画面では拡大・縮小ともになめらかに補間し、縮小用の画像（ミップマップ）を作って、歩いたときに模様がちらつかないようにしている。斜めから見る床がぼけないよう、異方性フィルタリング（最大8）もかけている。
- 画面では1マスが約48px（CSSピクセル）で映る。スマホは画面が2〜3倍細かいので、実際には1マスに約100〜150ドットを使う。128pxならほぼ1ドットずつ表示されるので、これより大きくしても見た目はほとんど変わらない。
- 1枚でも読み込めなかったときは、その特性は色だけで描く。

### 床1〜4
- マスの位置で決まった1枚が使われる（同じ場所はいつも同じ模様）。1種類で足りるなら、4枚とも同じ絵でよい。
- 真上から見た絵として描く。画面ではカメラが斜め上（約63度）から見下ろすので、少し縦に縮んで見える。
- 違う種類が隣り合うので、**縁の明るさと色はどの種類もそろえる**と継ぎ目が目立たない。今の仮の素材は、縁を目地へ向かってなめらかに沈ませた敷石にしている。

### 壁の上面
- 壁（箱）の上の面。真上から見た絵として描く。
- 隣の壁と並ぶので、上下左右の端で模様がつながるように描くと、ひと続きの壁に見える。端に縁取りを描くと、ブロックを並べたように見える（今の仮の素材はこちら）。

### 壁の側面
- 壁（箱）の横の面。4方向とも同じ絵が使われる。
- 壁の高さ1につき画像1枚分を貼る（今は高さ1なので、128px全体が使われる）。
- 左右の端で模様がつながるように描くと、横に並んだ壁が続いて見える（今の仮の素材は、段ごとに半分ずらしたレンガ積みで、左右の端でつながる）。

## 色と明るさについて
- 画面では、テクスチャに明るさを掛けて描く。今見えているマスは主人公から離れるほどなめらかに暗く（端で50%）、一度見たが今は見えていないマスは30%になる。
- 壁の側面は、上面より暗く描かれる（向きによって60〜85%）。
- 明るさはほぼ主人公のたいまつの光で決まり、光の届かない場所はかなり暗くなる。壁の上面はたいまつより高いので、たいまつの光は当たらない。暗い場所でも形がわかるよう、**真っ黒に近い色は避ける**。

## 画像から作る（`scripts/build-photo-textures.py`）

端どうしがつながる（並べても継ぎ目が出ない）正方形の画像1枚から、6枚をまとめて作る。

```bash
pip install pillow numpy
python3 scripts/build-photo-textures.py ice assets/texture-sources/ice.jpg
```

- 元の画像は `assets/texture-sources/{特性}.jpg`（または `.png`）に置く。1024×1024px くらいがよい
- 床は画像の4か所を切り出し、壁より明るくならないよう少し暗くして、縁を目地へなだらかに沈ませる。壁の上面は縁を明るく面取りした切り石、壁の側面は大きなブロックを2段積んだ形にする
- `assets/texture-sources/` に画像がある特性は、下の仮の素材のスクリプトでは上書きしない

## 仮の素材の作り直し

```bash
npx tsx scripts/build-textures.ts
```

端でつながるノイズを重ねて描いている（乱数は使わないので、作り直しても同じ絵になる）。色は `scripts/pixels.ts` の `PALETTES`。

## 確かめ方

```bash
npm run dev
```

`http://localhost:5173/?view=explore&trait=fire` のように特性を指定して開くと、そのテクスチャで探索画面を確かめられる（`&seed=1` で同じ階層、`&rank=3` で広さを指定）。
