# 状態異常（実装済み。2026-11-20）

敵の攻撃が当たると、**毒・鈍足・空腹**にかかることがある。**指輪が、かかる確率を変える**。治すのは**万能薬**（新しい道具）か、時間。
数字は `src/game/statuses.json`（管理画面の「状態異常」タブ）。働きは `src/game/status.ts`、`src/game/explore.ts`。

## ねらい
- 敵の動きにバリエーションを付ける（もとは、半分の敵が「近づいて殴るだけ」だった）。
- このゲームの軸は「探索前の準備」。状態異常は、**指輪・道具の選び方に答えが出る**形にする（何が来るかを知るほど、備えられる）。
- 「ダメージを増やすだけ」の個性にしない。歩き方・道具の使いどころが変わるものにする。

## 1. 状態異常の種類（主人公にかかる）
敵の攻撃が当たる（ダメージが入る）と、その敵に持たせた個性（`poison`・`chill`・`hunger`）の状態異常に、確率でかかる。突進・遠距離・離れるときの背後からの攻撃でも同じ。

| 状態異常 | 効き目 | 初期値 |
|---|---|---|
| 毒 `poison` | 毎ターン、HPが減る（守りは関係ない）。 | 確率30%・3ターン・毎ターン2 |
| 鈍足 `chill` | 歩くのに2ターンかかる（霜の床と同じ決まり。殴る・待つ・唱える・道具は1ターン）。歩くたびに歩数が1減る。 | 確率30%・2歩 |
| 空腹 `hunger` | 当たったときに、満腹度がその場で余分に減る（かかり続けない）。 | 確率30%・4減る |

- 同じ状態異常にもう一度かかると、残りが設定の長さまで延びる（重なって強くはならない。残りのほうが長ければそのまま）。ちがう種類は、同時にかかる。
- 階を移っても続く。中断データにも保存する（`PlayerStats.poisonTurns`・`chillSteps`）。力尽きたり踏破したりすれば消える。
- ボスは今回は与えない（段階ごとの行動に足せる）。個性のない敵は、確率を引かない（乱数も使わない）。
- 画面：ゲージの下に、かかっている毒・鈍足と、残りのターン数・歩数のバッジが出る（`.explore__ailments`）。かかった・切れたときはログに出る（「毒にかかった」「毒が抜けた」「足が重くなった（鈍足）」「足が軽くなった」「お腹が空いた」）。

## 2. 指輪が、かかる確率を変える
- かかる確率 ＝ 設定の確率 × **その敵の攻撃が受けるダメージの倍率**（指輪の耐性・弱点。`combat.ts` の `elementRate`。`enemyHitDamage` と同じ倍率）。上限は100%。
- 例：耐性30%の指輪なら、確率50%が35%に下がる。逆の属性の指輪（弱点）なら、少し上がる。万能の指輪は、どの敵にも少し効く（保険）。
- 氷の敵の鈍足には氷の指輪、というふうに、属性を知っていれば備えられる。無属性の敵（毒・空腹）には、無属性の指輪か万能の指輪。

## 3. 治す方法
- 時間で切れる（毒はターン数、鈍足は歩数）。
- 新しい道具「**万能薬**」（`panacea`。店の道具売り場。初期値60金貨）：毒と鈍足がすべて治る（1ターン使う）。かかっていないと使えない。回復薬は状態異常を治さない（役割を分ける）。空腹は、その場で満腹度が減るだけなので、治すものはない（食料で戻す）。

## 4. 持たせた敵（初期設定。管理画面の「敵」タブの「個性」欄で変えられる）
- 鈍足：氷の小鬼・氷のスライム・イエティ
- 毒：氷の甲虫・溶岩トカゲ・ゴブリン
- 空腹：大ネズミ（突進も）・闇コウモリ
- 新しい敵は足していない（モデル作りが重いので、必要な分だけ別に足す）。

## 5. 管理画面
- 「敵」タブの「個性」欄に、毒・鈍足・空腹が増えた。
- 「状態異常」タブ（`statuses.json`）：状態異常ごとの確率・毒のターン数とダメージ・鈍足の歩数・空腹で減る数。
- 「品物」タブに万能薬の値段。

## バランスの記録
深い祠（a_2）の「正しい準備」（自動プレイ。各属性 200〜300回の平均）。自動プレイは万能薬を使わない・耐性の指輪は準備の1つだけ、なので、遊ぶ人はこれより有利。

| 状態異常の数字 | クリア率 |
|---|---|
| 状態異常なし（確率0%） | 53% |
| 確率50%・鈍足3歩（最初の案） | 41%（氷のダンジョンが27%まで下がった） |
| 確率35% | 44% |
| 確率25% | 47% |
| **確率30%・鈍足2歩（採用）** | **約48%**（炎41・氷39・無60・光45・闇53） |

- 光のダンジョンは、状態異常を与える敵が出ないので変わらない。氷・炎が下がるのは、鈍足・毒の敵が氷のダンジョンに多いため。
- a_2 の設定（レベルの伸びなど）は変えていない（`hpPerLevel` を2上げると58%まで上がる。手を入れるなら、遊んでみてから）。
- 外れた準備は約6%、準備なしは約8%（状態異常の確率にも指輪の外れが響く）。
