# ダンジョンの記録

ダンジョンを選ぶ画面のカードに、そのダンジョンでのこれまでの記録を出す。

- 挑んだ回数：中断データから再開したものも含め、探索を終えた（帰還・倒れた・踏破）回数
- いちばん深く：たどり着いたいちばん深い階（「地下N階」、ボスの階まで行けば「最深部」）
- 踏破：最深部のボスを倒して帰った回数。1回でも踏破すると、カードに「踏破」の印が付く
- 取り戻した記憶：そのダンジョンのボスのうち、記憶を取り戻した数（●が取り戻した分）

記録はセーブ（`SaveData.records`）に、ダンジョンごとに残す（`src/game/records.ts`）。
知らないダンジョンや、おかしな値の記録は、読み込むときに捨てる。
