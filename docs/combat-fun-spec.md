## ② 武器の持ち替え（実装済み）

### ねらい
このゲームの軸は「探索前の準備」。**武器を2本持っていき、敵に合わせて戦闘中に持ち替える**ことで、準備に「何を組み合わせるか」が増え、戦闘中にも判断が生まれる。

### 決まり
- 武器は**メイン**と**サブ**の2本まで。**サブは、メインとちがう種類**（剣・ハンマー・杖）でなければならない（同じ種類は2本持てない）。
- サブ武器は**道具の枠を1つ使う**（`LOADOUT_CONFIG.subWeaponSlots`＝1。`src/game/data.ts`）。道具が上限いっぱいなら、道具を1つ減らしてから決める。
- **持ち替え＝1ターン**（`step` の `swap`。キーはQ、画面右の「持ち替え」ボタン）。サブがなければ使えない。
- **技ゲージは武器ごと**に持つ（持ち替えても、もう片方のゲージは残る）。**残響は、はめた武器（メイン）のもの**で、持ち替えると残響も一緒に入れ替わる（サブにはめた残響は今回はない）。
- 攻撃力は、武器の攻撃力と残響の分だけ入れ替わる（`weaponAtk`）。砥石などの付与は、持ち替えても残る。

### 画面
- 「見えている敵」に、**武器ごとのダメージの見込み**（`武器A n ／ 武器B m`）を出す。持ち替える価値が一目でわかる。
- 装備欄に「サブ：…」。持ち替えボタンにサブ武器のアイコン。
- 店（装備）：武器の取引に「サブにする／サブを外す」。キットの一覧に「サブ武器」の行。
  - メインを外す・サブと同じ種類の武器を買う（メインにする）と、サブは外れる。
  - 道具を持ちすぎているときは「道具を1つ減らすと、サブ武器を持っていけます」。

### 自動プレイ（バランス計測用）
- 隣の敵を殴る前に、サブ武器のダメージが今の**1.3倍以上**なら持ち替える（`AUTOPLAY_CONFIG.swapGain`）。
- 計測用の準備（`bestLoadout`）にはサブ武器を入れていない（これまでの a_2 の基準を保つため）。サブ武器の効果は、実際に遊んで確かめる。

### データ・保存
- `PlayerStats.sub`（`{ weapon, echoes?, skill }`）。中断データにも保存し、読み込み時に検証する（`runSave.ts`）。
- キット（`Kit.weapon2`）：持っていない・メインがない・同じ種類のときは読み込みで捨てる（`save.ts`）。

## ① 敵への状態異常とコンボ（実装済み）

### ねらい
炎・氷の呪文と砥石に「ダメージ以外の使いどころ」を足し、**武器の種類（剣・ハンマー・杖）と属性を組み合わせる**面白さを作る。持ち替え（②）と合わせて、「凍らせて→ハンマーに持ち替えて砕く」のような流れができる。

### 状態異常（敵にかかる）
| | 燃焼 | 凍結 |
|---|---|---|
| かかる元 | 炎の矢・炎の連矢（**必ず**）、炎の砥石で殴る（確率） | 氷の矢・氷の連矢（**必ず**）、氷の砥石で殴る（確率） |
| 効き目 | 毎ターン2ダメージ（守りは関係ない）。3ターン | 2ターン動けない（強衝撃の stun と同じ。殴ってこない・近づかない） |
| かからない敵 | 炎の敵 | 氷の敵・ボス |
| 弱点 | 氷の敵は +1ターン | 炎の敵は +1ターン |

- 連矢は、当たった敵のまわり8マスの敵にもかける。倒れた敵にはかからない。燃焼のダメージで倒しても、ふつうの報酬が入る。
- **蒸気**：燃えている敵に氷、凍っている敵に炎が当たると、蒸気になって**どちらも消える**（新しくもかからない）。
- かかった・かからなかった（「燃えない」「凍らない」）・蒸気は、ログに出る。凍結は動けないターン（`stun`）が切れると解ける。階を離れると、すべて消える（敵の様子を覚えるとき、燃焼・凍結は忘れる）。
- 砥石は、かからない敵には確率も引かない（乱数を使わない）。呪文はいつも必ず。

### コンボ
| 組み合わせ | 名前 | 働き |
|---|---|---|
| ハンマー × 凍結した敵 | 砕く | ダメージ ×2（`smashPercent`）。凍結が解ける |
| 剣 × 燃えている敵 | 焼き斬り | ダメージに、残りの燃焼ダメージ（残りターン × 毎ターン）を足す。火が消える |
| 杖で唱えた呪文 × 燃えている・凍っている敵 | 杖の共鳴 | 呪文のダメージ ×1.5（`spellPercent`） |

コンボが決まると、ログに「砕いた！」「焼き斬り！」「杖が共鳴した！」と出て、ダメージの出来事に `combo` が付く（⑥でダメージ数字の見た目に使う）。

### 数字（`statuses.json` の `foe`／管理画面の「状態異常」タブの下）
燃焼：砥石でかかる確率50%・3ターン・毎ターン2／凍結：確率50%・2ターン／弱点で延びるターン 1／砕く 200%／杖の共鳴 150%。

### 画面
- 凍った敵：氷の殻に包まれ、頭上に「氷」。燃えている敵：火の粉を出し続け、頭上に「炎」。かかった瞬間・砕いた・焼き斬り・共鳴に、破片と火花（`FOE_STATUS_FX`。`explore3dConfig.ts`）。
- 「見えている敵」に、「燃焼 n」「凍結 n」のバッジ（残りのターン数）。
- 開発用画面：`?foeburn=3&foefreeze=2` で、近くの敵が燃焼・凍結した状態で始まる。

### データ
`MapEnemy.burn`（`{turns, amount}`）・`frozen`（`stun` と一緒に使う）。中断データにも保存し、読み込み時に検証する（`runSave.ts`）。処理は `src/game/foeStatus.ts` と `explore.ts`（`inflict`・`burnTurn`・`staffBoost`・`playerAttack`）。

### いまはしないこと
- 燃える床・霜の床の上にいる敵を、燃やす・凍らせる。ボスの燃焼のダメージを、段階ごとに変える。光・闇の状態異常。
- 自動プレイは、コンボを狙わない（砥石・呪文は、これまでどおりに使うだけ）。

## ⑥ 手応え（その次）

- ヒットストップ（0.06〜0.09秒。弱点・砕くは長め）、ダメージ数字の見た目（弱点＝大きく黄色／耐性＝小さく灰色）。
- 倒したときの演出を体ごとに（やわらかい＝しぶき、かたい＝破片、霊体＝光の粒）。連続で倒すと音が上がる。
- 画面の縁の赤（HPが低いとき）。新しい効果音（凍結・燃焼・砕く・持ち替え）。
- 揺れ・ヒットストップを切る設定（音の設定のそば）。数字は `explore3dConfig` にまとめて、遊びながら調整できるようにする。
