# 記憶の「動く場面」（試作。2026-11-21）

ボスを倒した直後の記憶の画面（`MemoryScreen.tsx`。物語は `docs/story.md`）を、**時間で動く場面**にする。
動画ファイルは使わず、コード（CSS・canvas・時刻の関数）で動かす。まず**炎の魔獣**だけ作り、見た目を確かめてから、ほかのボスに広げる。

## 見え方（炎の魔獣・約21秒）
部屋の場面（これまでどおり）→「つづける」で動く場面が始まる。

| 時刻 | 場面 |
|---|---|
| 0〜1.4秒 | 暗い画面に、後ろの赤い光が浮かぶ |
| 1.4〜6秒 | 「大きな声が、家をゆらしていた。」文字がふるえる。声が響くたびに、画面が揺れて、ふちが赤く光り、火の粉が舞う |
| 6.6秒〜 | 「あの子は、布団の中で息をひそめた。」声が止み、光が暗くなって、ゆっくり脈打つ（息をひそめる）。火の粉はほぼ止まる |
| 10.2秒〜 | 「誰も来ない。耳をふさいでも、声は入ってきた。」遠い声が2回、小さく響く |
| 14.6秒〜 | 「やめて」と書き、取り消し線で消す。赤い引っかき傷が走る |
| 18.2秒〜 | 倒したボスの一文が、静かに出る |

- 「つづける」（最後は「目をさます」）は、いつでも押せる（押すと、場面を飛ばして次へ進む）。
- 「動きを減らす」設定のときは、これまでの記憶の画面のまま（揺れ・脈打ち・火の粉を出さない）。
- 文章は `story.ts` の `MEMORIES` をそのまま使う（動く場面は、出す時刻と動きだけを持つ）。読み上げには、きれいな文章を渡す。
- 表現の約束（`docs/story.md`）は変えない：家の中の場面や人物は描かず、感情の形（怒りと恐れ）を、光・揺れ・文字で表す。

## 迫力（2026-11-21）
- 声が響く瞬間に：画面が大きく揺れて傾き、ぐっと迫り（拡大）、ふちが赤く強く光り、後ろの光も一瞬明るくなり、下から火の粉が噴き上がる。声の行は大きく、赤く光ってふるえる。強さは声ごとに違う（`hits` の `power`）。
- 数字は `MOVIE_CONFIG`（`quake`・`punch`・`flash`・`burst`）。

## 音（2026-11-21）
音のファイルは使わず、合成（`src/audio/synth.ts`。Web Audio）。効果音の音量の設定に従い、音がオフのときは鳴らさない。
場面のはじめに、音の予定（`soundCues`）をまとめて予約し、場面を離れる（「つづける」で飛ばす）と、予約した音ごとすぐ静かにする（`openSoundBus`）。

| 音 | 鳴る場面 |
|---|---|
| 地鳴り `rumble` | 場面のはじめから、息をひそめる前まで、低く続く |
| 大きな声 `roar` | 声が響くたび（家をゆらす怒鳴り声と、叩きつける衝撃）。歪ませた重い衝撃・はじける全域の雑音と鋭い破裂・口の形が動く、ふるえる荒いうなり声・大きな部屋の響き（残響）を重ね、まとめて圧縮する。強さは `power`。（「家のきしみ（ガタガタ）」と「落ちる破片」は、乾いた「かこかこ」という音に聞こえたので外した） |
| 紙が燃えるチリチリ `sizzle` | ごく短い高い雑音の粒を、不規則に（ときどき静まり、ときどき密に）並べた、紙が燃えるような音。声のあいだは大きく、息をひそめるあいだは小さく（`sizzle_soft`）、「やめて」が燃えるとき（約3.4秒）は大きく、最後はそっと続く |
| 火の粉のはぜる音 `crackle` | 火の粉の勢いが強いあいだ（0.8秒ごと） |
| 心音 `heartbeat` | 息をひそめるあいだ、どくん、どくん（だんだん強く） |
| 書きなぐる音 `scratch` | 「やめて」を書くとき |
| 取り消し線 `strike` | 線を荒く引くとき |
| 静かな低い響き `hush` | 倒したボスの一文が出るとき |

最大の音は、満杯の1割ほど手前（割れない）に収めてある。

## 作り
- `src/ui/memoryMovie.ts`：場面の設定（`MOVIES`。ボスごとに、行の出る時刻・声が響く時刻と強さ・光と火の粉の強さの変わり方）と、時刻から決まる値の関数（`quakeAt` 揺れ・`flashAt` フラッシュ・`glowAt` 光・`stepEmbers` 火の粉・`itemTimes` 文字の出る時刻）。乱数は火の粉の出る位置だけで、揺れ・光・フラッシュは同じ時刻なら同じ値。数字は `MOVIE_CONFIG` に集めた（遊びながら調整する）。
- `src/ui/MemoryMovie.tsx`：1つの時計（requestAnimationFrame）で、揺れ・光・フラッシュ・火の粉の canvas を直接書き換える（React の描き直しは通さない）。文字の出方は CSS（`--at` 秒の遅れ。`styles.css` の `.mm__*`）。
- `src/ui/ScrawlParts.tsx`：書きなぐりの文字の部品（`MemoryScreen` から切り出した。見た目は変わらない）。
- `MOVIES` に載せたボスだけ、動く場面になる。載っていないボスは、これまでの画面。

## 確かめ方
開発用：`?view=memory`（`&boss=ice_colossus` などでボスを選べる。動く場面があるのは炎の魔獣だけ）。最後まで進むと、同じ場面をもう一度出す。
