# 記憶の「動く場面」（試作。2026-11-21）

ボスを倒した直後の記憶の画面（`MemoryScreen.tsx`。物語は `docs/story.md`）を、**時間で動く場面**にする。
動画ファイルは使わず、コード（CSS・canvas・時刻の関数）で動かす。まず**炎の魔獣**だけ作り、見た目を確かめてから、ほかのボスに広げる。

## 見え方（炎の魔獣・約22秒）
部屋の場面（これまでどおり）→「つづける」で動く場面が始まる。

| 時刻 | 場面 |
|---|---|
| 0〜1.4秒 | 暗闇の下から、炎が起こる。吸い込むような音の高まり |
| 1.4〜6秒 | 「大きな声が、家をゆらしていた。」文字がふるえる。声が響くたびに、画面が揺れて迫り、ふちが赤く光り、炎が燃え上がり、声の波（ぼやけた光の帯）が下から広がり、火の粉が噴き上がる |
| 6.6秒〜 | 「あの子は、布団の中で息をひそめた。」はっと息をのむ。四方から闇が迫り（布団の中）、外の音がこもる。心音が鳴り、闇が心音に合わせて脈打つ。終わりに、震えて吐く息 |
| 10.2秒〜 | 「誰も来ない。耳をふさいでも、声は入ってきた。」こもった中に、声が2回入ってくる（声の波は闇の上に出る。音も、その瞬間だけこもりが開く）。心音はだんだん速くなり、耳鳴りがする |
| 14.6秒〜 | 音がほとんど消える。「やめて」と書き、取り消し線で消す。赤い引っかき傷が走る |
| 16.75秒〜 | 「やめて」に火がつき、下から燃え尽きる（焦げた跡が、うすく残る）。言葉から火の粉が上る |
| 18.6秒〜 | いまに戻る：赤い色が冷めて灰色がかり、灰が降る。倒したボスの一文が、ぼやけた字から焦点を結ぶ。静かな和音 |

場面を通して、カメラはゆっくり寄り（手持ちのように、ゆるく揺れる）、フィルムの粒がうっすら乗る。書いたばかりの文字は、焼きつけたように熱く光り、少しずつ冷める。
「つづける」は場面のあいだ控えめにし、場面が終わると、はっきり見せる。

- 「つづける」（最後は「目をさます」）は、いつでも押せる（押すと、場面を飛ばして次へ進む）。
- 「動きを減らす」設定のときは、これまでの記憶の画面のまま（揺れ・脈打ち・火の粉を出さない）。
- 文章は `story.ts` の `MEMORIES` をそのまま使う（動く場面は、出す時刻と動きだけを持つ）。読み上げには、きれいな文章を渡す。
- 表現の約束（`docs/story.md`）は変えない：家の中の場面や人物は描かず（扉・人影・足音なども描かない）、感情の形（怒りと恐れ）を、光・炎・闇・揺れ・文字・音で表す。

## 迫力（2026-11-21）
- 声が響く瞬間に：画面が大きく揺れて傾き、ぐっと迫り（拡大）、ふちが赤く強く光り、後ろの光も一瞬明るくなり、下から火の粉が噴き上がる。声の行は大きく、赤く光ってふるえる。強さは声ごとに違う（`hits` の `power`）。
- 数字は `MOVIE_CONFIG`（`quake`・`punch`・`flash`・`burst`）。

## 場面の質を上げる（2026-11-21）
| 見え方 | 作り |
|---|---|
| 下で燃える炎 | 縦長のやわらかい光の粒（熱い黄色→橙→冷めた赤の3段の絵）を、下から次々に立ちのぼらせる（`stepFlames`・`flameLook`）。根元は勢いに応じて明るく燃える。勢いは `fire`（時刻ごとの値）に、声の瞬間の燃え上がりと、言葉が燃える明るさを足す（`fireAt`） |
| 声の波 | 声の瞬間に、下の炎から横に広いぼやけた光の帯が広がる（`ringsAt`）。闇の上に描く |
| 煙・灰 | 煙は、炎に照らされたうすい赤茶のもや（`stepSmoke`）。灰は、いまに戻ってから上から舞い落ちる（`stepAsh`） |
| 闇（布団の中） | 四方から迫る闇の深さ `enclose`。心音の脈（`pulseAt`）で、さらに少し迫る（`encloseAt`）。文字はその上なので読める |
| 光のゆらめき・カメラ | 後ろの光は炎のようにゆらめく（`flickerAt`）。カメラは場面を通してゆっくり寄り、ゆるく揺れる（`driftAt`）。赤い線が走るたび・燃え上がる瞬間に小さく揺れる（`kicksOf`） |
| 文字 | 書いたばかりの文字は熱く光って冷める（CSS `mm-sear`）。「やめて」は、取り消し線と赤い線のあと（`burnAt`）、橙に燃え上がり、下から燃え尽きる（CSS `mm-burn`：マスクの境目を下から上へ。長さ `burnFor`）。倒したボスの一文は、ぼやけて広がった字から焦点を結ぶ（`mm-echo-in`） |
| いまに戻る | 倒したボスの一文が出ると、赤い色が冷めて灰色がかる（色を混ぜる層 `.mm__grade`。重いので、その時刻まで置かない） |
| フィルムの粒 | 細かいノイズの絵を1度だけ作り、少しずつずらす（描き直さない） |

- 重さ：炎・煙・闇はぼやけた光なので、canvas は画面の点の細かさにかかわらず1倍で描く。CPU を4倍遅くした確認で、これまでの場面とほぼ同じ速さ（炎の多い場面で 約37 fps：前は 約39 fps）。
- 文字は、細い画面の端からはみ出さないよう、少し内側に寄せ、少し小さくし、1行ずつの横ずれを半分にした（動く場面だけ）。

## 音（2026-11-21）
音のファイルは使わず、合成（`src/audio/synth.ts`。Web Audio）。効果音の音量の設定に従い、音がオフのときは鳴らさない。
場面のはじめに、音の予定（`soundCues`）をまとめて予約し、場面を離れる（「つづける」で飛ばす）と、予約した音ごとすぐ静かにする（`openSoundBus`）。

| 音 | 鳴る場面 |
|---|---|
| 炎の音 `blaze` | 場面のはじめから、いまに戻るまで、ごうごうと低く、ゆっくり揺れて続く（外の音） |
| 吸い込む高まり `swell` | 最初の声の前：ノイズの帯域が上がりながら大きくなり、声の直前で途切れる（外の音） |
| 地鳴り `rumble` | 場面のはじめから、息をひそめる前まで、低く続く |
| 大きな声 `roar` | 声が響くたび（家をゆらす怒鳴り声と、叩きつける衝撃）。歪ませた重い衝撃・はじける全域の雑音と鋭い破裂・口の形が動く、ふるえる荒いうなり声・大きな部屋の響き（残響）を重ね、まとめて圧縮する。強さは `power`。（「家のきしみ（ガタガタ）」と「落ちる破片」、火の粉のはぜる音 `crackle`、「やめて」を書く音 `scratch`、取り消し線を引く音 `strike` は、乾いた「かこかこ」という音に聞こえたので外した） |
| チョークで書く音 `chalk` | 文字が出るあいだ（画面では、左から右へ、1文字ずつ書かれていく。長さは文字数に比例：1文字0.075秒、0.7〜1.8秒。`writeSeconds`）。粉っぽい摩擦の「シャッ、シャッ」を、重ねて途切れなくする（短い粒は並べない。かたかたした音になるため）。声の行・書いては消した言葉・塗りつぶしの帯・取り消し線は、力を込めて強く（`chalk_bold`）。音量は実測で合わせ、控えめにした（チョークは、背景でそっと鳴る程度）。文字は、書かれ始めてから少し遅れて見え始めるので、音も少し遅らせ（`soundLag`）、終わりを縮める（`soundTrim`）。取り消し線は、言葉が書かれた1.1秒あと、勢いよく引かれる |
| 赤い線が出る音 `slash` | 画面に赤い引っかき傷が走る（0.22秒ごとに1本ずつ、全部で4本。取り消し線の瞬間から）たびに、鋭く切り裂く「シュバッ」。高い雑音が低い方へすっと流れ、低い唸りが空気を切る。1本ごとに高さを変える（`MOVIE_CONFIG.slash`）。短い粒の連打にはしない（かこかこ、と聞こえるため） |
| 紙が燃えるチリチリ `sizzle` | ごく短い高い雑音の粒を、不規則に（ときどき静まり、ときどき密に）並べた、紙が燃えるような音。声のあいだは大きく、息をひそめるあいだは小さく（`sizzle_soft`）、「やめて」を書いてから燃えるまでは止み、燃えるとき（`burnFor`＋0.5秒）は大きく、最後はそっと続く |
| 息 `breath_in`・`breath_out` | 息をひそめるとき、はっと息をのむ。終わりに、こらえきれず震えて吐く |
| 心音 `heartbeat` | 息をひそめてから「やめて」の前まで、どくん、どくん（だんだん速く、強く。`heartTimes`）。画面の闇も、同じ拍で脈打つ |
| 耳鳴り `ring` | 耳をふさいでも声が入ってきたあと、高く細い音が、ゆっくり大きくなって消える |
| 火がつく音 `ignite` | 「やめて」に火がつく瞬間：ぼっと燃え上がり、燃え尽きるまで、ごうっと燃える |
| 静かな低い響き `hush`・和音 `pad` | 倒したボスの一文が出るとき：ラ・ミ・ド・ミのさびしい和音が、ゆっくり立ち上がり、遅れて高いシが灯り、部屋に響いて消える |

**外の音のこもり**：声・地鳴り・炎の音・高まりは「外の音」で、こもらせるフィルタを通す（`muffle`：通す高さの上限）。息をひそめると、こもる（布団の中）。こもった中に声が響くと、その瞬間だけ開く（耳をふさいでも、声は入ってくる。`muffleAt`）。「やめて」のあいだは、外がほとんど聞こえない（静けさの中で書く）。いまに戻ると、こもりが消える。
ほかの音（心音・息・耳鳴り・書く音・燃える音・和音）は内側の音で、こもらない。予約は `src/ui/movieSound.ts`（画面と、音の書き出しの確かめが、同じ関数を使う）。

重なった音が割れないよう、場面の音の出口に割れ止め（`sceneLimiter`）を置いた。

### 音の質（2026-11-21）
- **左右の広がり**：炎の音・チリチリ・叩きつける雑音・和音は、左右で違う音にした。チョークは、書く位置にあわせて左から右へ動く。赤い線の音は、画面を走る線の向き（左から右・右から左）に動く（`slashPans`）。耳鳴りは、左右の耳に少しずれた音を入れ、頭の中でかすかにうなる。心音は真ん中（体の中）。
- **場面の響き**：暗く広い空間の響き（約2.6秒。時間がたつほど高い音から消える。`sceneSpace`）へ、音ごとに決めた量だけ送る（`SPACE_SEND`：心音・書く音は少なく、和音・赤い線・燃え上がりは多く）。全体は、ゆるく圧縮してひとつの音にまとめる（グルー）。
- **素材**：ノイズの素材を4秒にした（長い炎の音で、くり返しの模様が聞こえない）。炎・息・地鳴りは、自然な色のノイズ（pink：ざーっ、brown：ごーっ）。
- **スマホのスピーカー**：心音・地鳴り・声の衝撃のような低い音は、小さなスピーカーでは鳴らないので、歪ませて作った倍音（約220〜1100Hz）を足す（`presence`）。心音の、スマホで聞こえる帯域の大きさは、前の約20倍。
- **大きな声**：口の形（3つの響きの山。母音「お」→「あ」→「お」）・声のゆれ（2つの速さ）・1オクターブ下の唸り・息のかすれを重ね、2つの声を少しずらして左右に置き、左右の壁の跳ね返りを足した。
- **息**：息の響きの山を2つ持たせ、吐く息は不規則に震える。
- **大きさの釣り合い**（`MIX_DB`）：音を1つずつ書き出し、前の版と比べて決めた。チョークは前より少し小さく、炎の音は背景で聞こえる程度に、息はかすかに。外の音は、こもるほど少し小さくもなる（`worldLevel`）。全体の大きさは前と同じ（-18.3 LUFS。前は -18.2）で、静かな所と大きな所の差は少し広がった（LRA 8.8 → 10.8）。まとめの圧縮のあと持ち上げず、割れ止めの手前にゆとりを残す。
- **プチッという雑音を直した**：音の包絡（音量の山）の初めの値が既定の 1 のままだと、鳴り始めの時刻の丸めによって、ノイズの1点が素通りして「プチッ」と鳴ることがあった（倒したボスの一文の瞬間など。前の版にもあった）。包絡は、初めの値を 0 にしてから予定を置く（`synthParts.ts` の `tone`・`hiss` を使う、ゲームの効果音も同じく直る）。
- 作り：場面の音は `src/audio/sceneSynth.ts`、部品（ノイズの素材・発振器・歪み・響き・左右・倍音）は `src/audio/synthParts.ts`、ゲームの効果音は `src/audio/synth.ts`。
音は、場面のはじめに予約する（画面の時計と同じ瞬間に始まるよう、予約の余裕は0.02秒）。

## 作り
- `src/ui/memoryMovie.ts`：場面の設定（`MOVIES`。ボスごとに、行の出る時刻・声が響く時刻と強さ・光と火の粉の強さの変わり方）と、時刻から決まる値の関数（`quakeAt` 揺れ・`flashAt` フラッシュ・`glowAt` 光・`stepEmbers` 火の粉・`itemTimes` 文字の出る時刻）。乱数は火の粉の出る位置だけで、揺れ・光・フラッシュは同じ時刻なら同じ値。数字は `MOVIE_CONFIG` に集めた（遊びながら調整する）。
- `src/ui/MemoryMovie.tsx`：1つの時計（requestAnimationFrame）で、揺れ・光・フラッシュ・炎・煙・火の粉・灰・闇の canvas を直接書き換える（React の描き直しは通さない）。文字の出方は CSS（`--at` 秒の遅れ。`styles.css` の `.mm__*`）。
- `src/ui/movieSound.ts`：場面の音を、外の音（こもらせる）と内側の音に分けて、まとめて予約する。
- `src/ui/ScrawlParts.tsx`：書きなぐりの文字の部品（`MemoryScreen` から切り出した。見た目は変わらない）。
- `MOVIES` に載せたボスだけ、動く場面になる。載っていないボスは、これまでの画面。

## 確かめ方
開発用：`?view=memory`（`&boss=ice_colossus` などでボスを選べる。動く場面があるのは炎の魔獣だけ）。最後まで進むと、同じ場面をもう一度出す。
