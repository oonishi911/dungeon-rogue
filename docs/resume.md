# 中断した探索の「続きから」（2026-11-28）

探索の途中の状態は、1手ごとにブラウザへ保存している（`runSave.ts`、`dungeon-prep/run`）。前は、ページを開き直すといきなり探索の画面に戻っていた。今は「続きから」の画面（`ResumeScreen.tsx`）を挟む。

## いつ出るか
- ページを開いたとき、中断データがあれば
- 探索の画面の「中断してもどる」（右の欄、リタイアの上）を押したとき。探索はそのまま残る

## 画面に出すもの（`runSummary.ts`）
ダンジョンの名前・地下N階（ボスの階は「最深部」）／全M階（ボスの階をふくむ）・体力の棒・レベル・体力・倒した敵・金貨・歩いたターン・いつ中断したか（「たった今」「3分前」「2時間前」「1日前」）。

## 選べること
- 続きから：探索の画面に戻る（中断した状態のまま）
- あきらめる：確かめたあと、リタイアしたことにして結果の画面へ。金貨は力尽きたときと同じだけ持ち帰り、拾った刻印武器と残響は倉庫に入る（探索の画面のリタイアと同じ）

## 保存の形
中断データに `savedAt`（保存した時刻、ミリ秒）を足した。前の版の保存には無いので、無ければ「いつか」は出さない。
