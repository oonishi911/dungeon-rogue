# 音と演出の磨き込み（2026-11-28）

音のファイルは増やさず、Web Audio の合成（`src/audio/synth.ts`・`src/audio/bossMusic.ts`）と、画面の重ね書き（CSS）だけで足した。
どれも設定の画面の「演出」で、あり・なしを切り替えられる（`feelSettings.ts` の `bossMusic` / `stairsFx` / `endFx`。ふだんはすべて「あり」）。

## ボス戦の音楽（`bossMusic`）
- 最深部（ボスの階）にいて、まだ決着がついていないあいだ流れる。ふだんの環境音は止まり、ボスの階を出る・踏破・力尽きる・設定で切ると、0.8秒かけて小さくなる。環境音に戻るときは、いつものとおり2秒かけて大きくなる。
- 音量は「環境音」のつまみに従う（音全体のオフにも従う）。
- 中身：テンポ138、8小節のくり返し（約13.9秒）。コードは Am → F → G → E（2小節ずつ）。低いベース（のこぎり波）の8分音符、キック、スネア（2拍目・4拍目）、ハイハット、コードの刺す音。
- 何をいつ鳴らすかは、音を出さない関数 `bossStep(小節, 16分音符の位置)` で決め、`startBossMusic` が 0.4 秒先までの音を 0.1 秒ごとに予約していく。

## 階段を降りる演出（`stairsFx`）
- 音：石を踏む低い音が3段ぶん下がり、最後に遠くへ響く（合成音 `stairs`）。
- 画面：階が変わった瞬間に真っ暗になり、0.7秒で明るく戻る（`.explore__fade`）。
- 階が上がったときだけ（上り階段や、記憶・やり直しでは出ない）。

## 踏破・力尽きたときの演出（`endFx`）
- 踏破：上がっていく和音にきらめき（合成音 `clear`）。画面は白い光がふくらんで薄れる（1.4秒）。
- 力尽きた：重い一撃のあと沈んでいく音（合成音 `defeat`）。画面はふちから暗く赤く沈む（1.6秒）。
- 音は、倒した一撃の音と重ならないよう、0.25秒あとに鳴る。

## 動きを減らす設定
ブラウザの「動きを減らす」がオンのときは、画面の演出（暗転・光・沈み）は一瞬で終わる（音は設定どおり）。
