# 管理画面の「クリア率を測る」（2026-11-29）

管理画面でダンジョンの設定（成長・満腹度・敵の数など）を変えたとき、公開する前に、クリア率がどう変わるかを確かめる。
2026-11-28 に、成長の値（レベルアップごとの増え方）を変えただけで、気づかないうちにクリア率が約70%から0%になったため。

## 使い方
1. ダンジョンのタブ（階の数・広さ・満腹度／HP・レベル・強敵の報酬 など）で値を変える
2. 画面の下のほうの「クリア率を測る（ダンジョン名）」の「クリア率を測る」を押す（30秒〜1分。「やめる」で止められる）
3. 公開版と、変えたあとのクリア率が、属性ごとと平均で並ぶ。気を付けることがあれば ⚠ で出る
4. 「変更を公開」の上の「クリア率の見込み」に、変えたダンジョンごとの結果がまとまる（まだ測っていない・測ったあとに変えた、も出る）

## 測り方
- バランスの記録（`npm run balance:report`）と同じ条件：自動プレイ・正しい準備（その属性に効く防具と武器＋回復薬・食料）
- 属性ごとに20回（速さを優先。±10ポイントほどぶれる）。正確に測るときは、公開したあと `npm run balance:report`
- 画面が止まらないよう、Web Worker（`src/game/clearCheck.worker.ts`）で動かす。中身は `src/game/clearCheck.ts`
- 測れるのはダンジョンの設定だけ。敵・品物・残響・状態異常のタブで変えたものは入らない（遊ぶときの表がゲームの始まりに作られるため）
- まだ公開していない新しいダンジョンも測れる（公開版の行は出ない）

## ⚠ が出るとき（`CHECK_LIMITS`）
| 条件 | 例 |
|---|---|
| 平均が目標（70%）から20ポイントより外れる | 平均45%、平均95% |
| 正しい準備でも20%未満の属性がある | 闇だけ10% |
| 公開版から平均が20ポイント以上動く | 74% → 21% |

⚠ が出ても公開はできる（止めはしない）。意図した変更なら、そのまま公開してよい。
