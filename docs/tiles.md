# タイル素材の仕様

> **2026-11-05：探索画面を3D表示に切り替えたため、この素材は2D表示（`?render=2d`、WebGL2 が使えない環境）でだけ使われる。** 3D表示の床と壁の素材は [textures.md](textures.md)。

ダンジョンの床・壁・階段・宝箱の画像。ダンジョン特性ごとに見た目を変える。
今は `scripts/build-tiles.ts` で作った仮の素材が入っている。同じ配置で描いたPNGに差し替えれば、そのまま画面に反映される。

## ファイル

| 特性 | ファイル |
|---|---|
| 炎 | `public/tiles/fire.png` |
| 氷 | `public/tiles/ice.png` |
| 無属性 | `public/tiles/neutral.png` |
| 光 | `public/tiles/light.png` |
| 闇 | `public/tiles/dark.png` |

- PNG、**128×128px**、1マス32×32px。
- ドット絵として描く。ぼかしや半透明の縁（アンチエイリアス）は使わない。
- 透明な部分には、下に床が描かれる（壁も床の上に重ねて描く）。
- ボス階も、そのダンジョンのタイルを使う。

## 配置

```
 x:  0      32      64      96     128
y:0 ┌───────┬───────┬───────┬───────┐
    │ 床1   │ 床2   │ 床3   │ 床4   │
 32 ├───────┼───────┼───────┼───────┤
    │ 見本  │ 内角  │ 階段  │ 宝箱  │
 64 ├───────┴───────┼───────┴───────┤
    │               │               │
    │ 外角・辺・中央 │    （空き）    │
    │  （64×64px）  │               │
128 └───────────────┴───────────────┘
```

- **床1〜4**：マスの位置で決まった1枚が使われる（同じ場所はいつも同じ模様）。1種類で足りるなら、4枚とも同じ絵でよい。
- **階段・宝箱**：床の上に重ねて描く前提なら、背景は透明でもよい。
- 左下の64×96px（見本・内角・外角/辺/中央）が**壁のオートタイルのひな形**。

## 壁のひな形（オートタイル）

壁は、隣のマスとのつながりに合わせて形が変わる。1マスを16×16pxの4分の1マス4つに分け、それぞれにひな形から切り出した部品を使う。描くのは次の3つだけで、47通りのつながり方をすべて表せる。

### 外角・辺・中央（64×64px）
**2×2マスの大きさの、ひとかたまりの壁**として描く。外周が床に接する縁、内側が壁の中身になる。

```
16pxの部品で見ると 4×4 個
┌──┬──┬──┬──┐
│外│上│上│外│   外：外角（角が床に接する）
├──┼──┼──┼──┤   上・下：上下の辺（上か下が床に接する）
│左│中│中│右│   左・右：左右の辺（左か右が床に接する）
├──┼──┼──┼──┤   中：中央（周りがすべて壁）
│左│中│中│右│
├──┼──┼──┼──┤
│外│下│下│外│
└──┴──┴──┴──┘
```

### 内角（32×32px）
上下左右は壁で、**斜めのマスだけが床**のときに使う。四隅それぞれに、斜めの床に接する小さな角を描く。中央の部分は使われない。

### 見本（32×32px）
周りに壁がない、単独の壁の完成形。**組み立てには使わない**。描く人が仕上がりを確かめるためのもの。

## 描くときの注意

- 霧の向こうの形がわからないよう、**まだ見ていない隣のマスは壁として扱う**。歩いて霧が晴れると、縁の形が変わる。
- 4分の1マスを組み合わせるので、外角・辺・中央の境目（16pxごと）で模様がつながるように描く。

## 確かめ方

```bash
npm run dev
```

`http://localhost:5173/?view=explore&trait=fire` のように特性を指定して開くと、そのタイルで探索画面を確かめられる（`&seed=1` で同じ階層を指定）。
