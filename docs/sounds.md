# 効果音と環境音

効果音と環境音は録音ではなく、`scripts/build-sounds.py` で合成して `public/sounds/` に mp3 で書き出す。

```bash
pip install numpy scipy   # mp3 への変換に ffmpeg も使う
python3 scripts/build-sounds.py
```

## 今ある音

| 音 | ファイル | 鳴る場面 |
|---|---|---|
| 足音 | `step-{特性}-1〜4.mp3` | 主人公が同じ階の中で1歩進んだとき。今いるダンジョンの特性の足音を鳴らす |
| 宝箱の音 | `chest-open.mp3` | 宝箱から金貨か道具を取ったとき（持ち物がいっぱいで何も取れなかったときは鳴らさない）。木の宝箱のふたが「ぎー」ときしみながら開き、「ガコッ」と重く当たって止まる（約0.9秒）。足音よりはっきり聞こえる大きさ |
| 環境音（無属性） | `ambient-neutral.mp3` | 無属性のダンジョンにいるあいだ、くり返し流す。洞窟を吹き抜ける風のうなり（低いゴォーという風に、岩の穴で鳴るウォー・ヒュウといううなりと、かすかなサーという空気の音）。左右2チャンネル、24秒でつながるループ |
| 環境音（光） | `ambient-light.mp3` | 光のダンジョンにいるあいだ、くり返し流す。磨かれた石の神殿の広間：遠くの合唱のような、やわらかく澄んだ明るい和音がゆっくり満ち引きし、遠くの小さな鐘（2回）が広間に長く響く。高い窓からのそよ風と、光の粒のような小さなきらめきが混ざる。左右2チャンネル、24秒でつながるループ |
| 環境音（闇） | `ambient-dark.mp3` | 闇のダンジョンにいるあいだ、くり返し流す。光の届かない硬い石の洞窟の奥：わずかに高さのずれた低い音がうなり合う不気味な響きに、人の声のようにも聞こえるささやきの風、遠くのうめき声（2回）、暗がりで石が落ちて転がる音（4回）が混ざる。左右2チャンネル、24秒でつながるループ |
| 環境音（炎） | `ambient-fire.mp3` | 炎のダンジョンにいるあいだ、くり返し流す。溶岩の流れる火山の洞窟：低くうねる地鳴りに、粘りのある溶岩の泡がボコッと弾ける音（11回）、まばらにはぜる火の音、遠くで蒸気が噴き出す音（2回）が混ざる。左右2チャンネル、24秒でつながるループ |
| 環境音（氷） | `ambient-ice.mp3` | 氷のダンジョンにいるあいだ、くり返し流す。氷の洞窟：冷たく細いヒュウという風に、遠くで氷が低くきしむ音（2回）と割れる音（1回）、洞窟に響く水滴（6回）、氷の粒がふれ合う小さなきらめきが混ざる。左右2チャンネル、24秒でつながるループ |

足音は特性ごとに、歩く地面を変えている（鳴らす特性は `src/audio/sound.ts` の `STEP_TRAITS`）。

| 特性 | 地面 | 音 |
|---|---|---|
| 無属性 | 土 | 低く重いドスッという音に、土の粒がこすれるかすかな音。響きは少ない。とても低い音はスマホのスピーカーでは鳴らないので、少し上の低い音を厚くしている |
| 炎 | 焼けて硬くなった、細かく尖った石 | 硬い石に当たるカッという音のあと、石の先端が砕けるゴリッという音と、尖った先が折れるパキッという鋭い音 |
| 氷 | 雪 | 左右の足で、シャリッ（細かい氷の粒が砕ける軽い音）とジャリッ（雪が押し固められる粗い音）を交互に鳴らす。氷の洞窟の閉じた空間に、明るく強い響きが約1.2秒残り、左右に広がる |
| 光 | 磨かれた石の神殿 | 硬く澄んだカツッという音。広い広間なので、残響がいちばん長い |
| 闇 | 硬い石の洞窟 | 固いカツッという音に、暗い洞窟のこもった残響が長く残る |

- どの特性の足音も、光の足音と同じくらいの大きさに聞こえるようにそろえている（光の足音を最初に入れ、音量の設定もそれで決めたため）
- 聞き比べ用に、`python3 scripts/build-sounds.py --preview <書き出し先>` で、特性ごとにゲームと同じ0.27秒間隔で7歩鳴らした音を書き出せる
- 一歩分の音を4種類作る。奇数番が片方の足、偶数番がもう片方の足の音で、ゲームでは左右の足で交互に、その足の音から前と違うものを選ぶ。音の高さも少し（±4%）変えて、同じ音のくり返しに聞こえないようにする
- 氷の足音は、氷の洞窟に響く残響を左右で少しずつ違えているので、左右2チャンネルの音にしている（ほかは1チャンネル）
- 鳴らす音を足すときは、`scripts/build-sounds.py` で作り、`src/audio/sound.ts` に書き足す

## 環境音

- ダンジョンにいるあいだ、特性ごとの環境音をくり返し流す（すべての特性にある）。流し始めは2秒かけてなめらかに大きくし、ダンジョンを出るときは1秒かけて小さくする
- くり返しの継ぎ目が聞こえないよう、強弱や音の高さの揺れは、どれも24秒でちょうど元に戻る周期にして、最後の3秒を最初になめらかに重ねている
- 足音や宝箱の音のじゃまにならないよう、小さめに作る。ほかの特性の環境音も、無属性の風の音と同じくらいの大きさにそろえる
- ときどき鳴る音（氷が割れる音など）は、ループの中の決まった時刻に置く。ループの終わりからはみ出した響きは、最初に回す
- 別のタブやアプリに切り替えたあいだは止め、戻ったら続きから鳴らす

## 設定

- 探索画面の上のスピーカーのボタンで、音のオン・オフと、効果音・環境音それぞれの音量（0〜100%）を変えられる。効果音の音量のつまみを離すと、その音量で試しに鳴る。環境音は流れているので、つまみを動かすとそのまま大きさが変わる
- 設定はブラウザに保存し、次に遊ぶときも同じにする（`src/storage.ts`）。保存できないときも、その回のあいだは設定どおりに鳴る
- 音量は、つまみの位置の2乗を掛ける（耳には音の大きさの違いが比で聞こえるので、つまみの動きと聞こえ方の変わり方を近づける）
- スマホのブラウザは、画面に触れるまで音を出させてくれない。最初に画面に触れたときに音の準備をする（`src/main.tsx`）。環境音も、そのときに流れ始める
- iPhone は、本体の消音スイッチが入っていると、ブラウザの音も鳴らない
