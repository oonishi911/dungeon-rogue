# 効果音

効果音は録音ではなく、`scripts/build-sounds.py` で合成して `public/sounds/` に mp3 で書き出す。

```bash
pip install numpy scipy   # mp3 への変換に ffmpeg も使う
python3 scripts/build-sounds.py
```

## 今ある音

| 音 | ファイル | 鳴る場面 |
|---|---|---|
| 光のダンジョンの足音 | `step-light-1〜4.mp3` | 光のダンジョンで、主人公が同じ階の中で1歩進んだとき |

- 足音は特性ごとに作る。磨かれた石の神殿を硬い靴で歩く、硬く澄んだ音で、残響が長い。ほかの特性の足音はまだないので鳴らさない
- 一歩分の音を4種類作り、一歩ごとに前と違うものを選んで、音の高さも少し（±4%）変える。同じ音のくり返しに聞こえないように
- 鳴らす音を足すときは、`scripts/build-sounds.py` で作り、`src/audio/sound.ts` に書き足す

## 設定

- 探索画面の上のスピーカーのボタンで、効果音のオン・オフと音量（0〜100%）を変えられる。音量のつまみを離すと、その音量で試しに鳴る
- 設定はブラウザに保存し、次に遊ぶときも同じにする（`src/storage.ts`）。保存できないときも、その回のあいだは設定どおりに鳴る
- 音量は、つまみの位置の2乗を掛ける（耳には音の大きさの違いが比で聞こえるので、つまみの動きと聞こえ方の変わり方を近づける）
- スマホのブラウザは、画面に触れるまで音を出させてくれない。最初に画面に触れたときに音の準備をする（`src/main.tsx`）
- iPhone は、本体の消音スイッチが入っていると、ブラウザの効果音も鳴らない
