# 刻印装備と残響（設計。2026-11-19）

武器と防具に、**刻印スロット**を付ける。スロットにはめるアイテムの総称は**残響**。
どちらも買えない。敵が、ごく稀に落とす。今の「+の数が大きい品を買い替える」だけの強化に、選ぶ楽しみを足す。

**状態：設計の段階。まだ作っていない。** 数字は仮で、作るときにバランスの試験で調整する。

## 決まったこと（2026-11-19、ユーザーの選択）

| 項目 | 決めたこと |
|---|---|
| 総称 | **残響**（ざんきょう）。迷路が忘れた記憶の残り、という物語の言葉にする |
| 刻印スロット付きの装備 | **買えない**。敵がごく稀に落とす。店で買える+の付いた武器・防具は、今のまま残す |
| 残響の落とし方 | 敵の**属性・体質に合う**残響が落ちる（炎の敵→炎の残響、硬い敵→硬い残響）。どのダンジョンで集めるかが、準備の判断になる |
| 力尽きたとき | **失わない**。拾った残響と刻印装備は、そのまま倉庫に入る |
| 付け替え | **自由**。外した残響は倉庫に戻る。忘れ物屋で、装備と残響の組み合わせを考える |

## 刻印装備

- **種類**：今の武器（剣・槌・杖）と防具（耐火・耐氷のマント・鎧・光の衣・闇の衣）と同じ形で、刻印スロットが付いたもの。名前は「刻まれた剣」「刻まれた耐火のマント」のように、頭に「刻まれた」を付ける。
- **強さ**：基本の強さは、同じ種類の+の付いた品と同じ段階にする。ダンジョンが難しいほど、高い段階が出る（仮：標準 +2〜+4、A-1 +3〜+6、A-2 +5〜+8）。基本の強さは、店の品を超えない。強さの差は、スロットで出す。
- **スロット数**：1〜3個。出やすさは、1個60%・2個30%・3個10%（仮）。
- **落とす確率**（仮）：通常の敵0.3%・強敵3%・ボス10%。1回の挑戦（敵30〜60体）で、出会える確率は1割ほど。
- **何が出るか**：倒した敵のダンジョンに合う武器か防具。武器か防具かは、半々。
- **手に入れ方**：倒したとき、その場で倉庫に入る（道具枠は使わない）。「刻まれた剣を拾った」と記録に出す。
- 一度手に入れたら、力尽きても、なくならない。同じ種類を何個でも持てる（スロットが違うので、別のもの）。

## 残響

| 残響 | 武器にはめたとき | 防具にはめたとき | 落とす敵 |
|---|---|---|---|
| 炎の残響 | 通常攻撃に炎が付く（炎の砥石と同じ相性表） | 炎のダメージを、10%余分に軽減 | 炎の敵 |
| 氷の残響 | 通常攻撃に氷が付く | 氷のダメージを、10%余分に軽減 | 氷の敵 |
| 光の残響 | 通常攻撃に光が付く | 光のダメージを、10%余分に軽減 | 光の敵 |
| 闇の残響 | 通常攻撃に闇が付く | 闇のダメージを、10%余分に軽減 | 闇の敵 |
| 柔らかい残響 | 柔らかい敵へのダメージ +25% | 柔らかい敵から受けるダメージ -15% | 柔らかい体の敵 |
| 硬い残響 | 硬い敵へのダメージ +25% | 硬い敵から受けるダメージ -15% | 硬い体の敵 |
| 霊体の残響 | 霊体の敵へのダメージ +25% | 霊体の敵から受けるダメージ -15% | 霊体の敵 |
| ただの残響 | 攻撃力 +1 | 防御 +1 | 無属性・普通の体の敵 |

- 残響は、はめる先で効果が変わる（1つの品物に、武器用と防具用の2つの効果がある）。品物は8種類だけで済む。
- 同じ残響を、複数のスロットにはめられる。効果は足し算（属性の付与は重ならず、1つだけ効く。砥石を使ったときは砥石の属性が先）。
- 敵の属性と体質の両方に合うとき（炎で柔らかい猟犬など）は、どちらかを半々で落とす。
- **落とす確率**（仮）：通常の敵4%・強敵25%・ボス必ず1個。残響は、刻印装備よりずっと出やすい（装備は出会うだけで貴重、残響は組み合わせを選ぶ材料）。
- 手に入れ方は、刻印装備と同じ。倉庫に直接入り、力尽きても、なくならない。

## 付け替え（忘れ物屋）

- 忘れ物屋に、**「刻印」の売り場（タブ）**を足す。持っている刻印装備を選び、スロットを押して、倉庫の残響をはめる・外す。
- 付け替えは、何度でも、無料。外した残響は倉庫に戻る。
- 刻印装備も、ふつうの武器・防具と同じように、「装備する」で付けられる（装備枠は、武器1つ・防具1つのまま）。
- 探索中は付け替えられない（準備の段階の決定にする）。

## 情報屋との関係

- 情報屋から「多い魔物の体」や「ボスの属性」をはっきり聞けると、どの残響をはめるべきかが決まる。残響は、情報を集める意味を強める。
- 店の「おすすめ」の印（`shop.ts` の `recommended`）は、残響にも付ける（聞いた情報に合う残響）。

## 物語との関係

- 敵は、迷路に残った記憶の影。残響は、その名残。説明文は、短く、静かに書く（例：「炎の残響：熱の名残。耳の奥で、まだ鳴っている。」）。
- 物語の約束（`docs/story.md`）のとおり、感情は抽象的に書き、方法や場面には触れない。

## 作るときの方針（メモ）

- 今の持ち物は、品物のID（`ItemId`）で、種類ごとに1つ（`save.owned`）。刻印装備は、1つ1つが別のもの（スロットが違う）なので、**自分のIDを持つ刻印装備の一覧**をセーブデータに足す（基本の品の種類・段階・スロットにはめた残響）。残響は、種類ごとの数を倉庫に持つ。昔の記録は、空から始める。
- 出発の持ち物（`Kit`・`Departure`）で、武器と防具に、刻印装備のIDを指せるようにする。探索の途中保存（`runSave.ts`）も、はめた残響まで保存する。
- 強さの計算（`combat.ts` の `playerStats` など）に、はめた残響の効果を足す。属性の付与は、砥石の付与の仕組み（`weaponElement`）に合流させる。
- 敵の落とし物（`explore.ts` の落とし物の判定）に、刻印装備と残響を足す。確率は `REWARD_CONFIG` に置く。
- 試験：落とす確率と種類の決まり、残響の効果の計算、付け替え、保存と読み込み、力尽きても失わないこと。バランスの試験で、刻印装備なしでもクリアできる（刻印装備は、なくても困らない上乗せ）ことを確かめる。
- 画面：忘れ物屋の「刻印」のタブ、探索中の装備の一覧にスロットを表示、探索の記録に拾った記録。3Dの武器の見た目は、スロットが埋まるとうっすら光る程度にする（あとで）。

## 決めたいこと

- 確率・スロット数・段階の数字（上の「仮」）。
- ボスが、必ず残響を1個落とすか（今は必ず）。
- 宝箱からも、残響や刻印装備が出るか（今は出ない。敵が落とすだけ）。
- 残響の効果の大きさ（+25%・-15%・10%は仮）。
- 残響の種類を、あとから増やすか（例：満腹度を節約する残響、技ゲージがたまりやすい残響）。
