# 刻印装備と残響（設計。2026-11-19）

武器と防具に、**刻印スロット**を付ける。スロットにはめるアイテムの総称は**残響**。
どちらも買えない。敵が、ごく稀に落とす。今の「+の数が大きい品を買い替える」だけの強化に、選ぶ楽しみを足す。

数字は**管理画面の「残響」タブ**で変えられる（設定ファイルは `src/game/echoes.json`）。下の数字は、初期の値。

## 決まったこと（2026-11-19、ユーザーの選択）

| 項目 | 決めたこと |
|---|---|
| 総称 | **残響**（ざんきょう）。迷路が忘れた記憶の残り、という物語の言葉にする |
| 刻印スロット付きの装備 | **買えない**。敵がごく稀に落とす。店で買える+の付いた武器・防具は、今のまま残す |
| 残響の落とし方 | 敵の**属性・体質に合う**残響が落ちる（炎の敵→炎の残響、硬い敵→硬い残響）。どのダンジョンで集めるかが、準備の判断になる |
| 力尽きたとき | **失わない**。拾った残響と刻印装備は、そのまま倉庫に入る（リタイアも同じ） |
| 付け替え | **自由**。外した残響は倉庫に戻る。忘れ物屋の「刻印」の売り場で行う |
| 宝箱 | 宝箱からは**出ない**。敵が落とすだけ |
| 数字 | 管理画面で変えられる |

## 刻印装備

- **種類**：今の武器（剣・槌・杖）と防具（耐火・耐氷のマント・鎧・光の衣・闇の衣）と同じ形で、刻印スロットが付いたもの。名前は「刻まれた」＋元の名前。
- **何が出るか**：倒した敵に合う武器か防具（半々）。武器は敵の体質に効く種類（柔らかい→剣、硬い→槌、霊体→杖、普通の体→どれか）。防具は敵の属性に効く種類（炎→耐火のマント、氷→耐氷のマント、無属性→鎧、光→光の衣、闇→闇の衣）。
- **強さ**：元の品の段階は、設定の範囲（初期は2〜4段）からくじで決まる。強さの差は、スロットで出す。
- **スロット数**：1〜3個。出やすさは、初期は 1個60%・2個30%・3個10%。
- **落とす確率**（初期）：通常の敵0.3%・強敵3%・ボス10%。
- 倒したとき、その場で倉庫に入る（道具の枠は使わない）。同じ種類が何個でも持てる（スロットが違うので、別のもの）。

## 残響

敵が落とす確率（初期）：**通常の敵2%・強敵10%・ボス50%**。

| 残響 | 武器にはめたとき | 防具にはめたとき | 落とす敵 |
|---|---|---|---|
| 炎の残響 | 通常攻撃に炎の力が付く（砥石の力が先） | 炎の敵から受けるダメージ −10% | 炎の敵 |
| 氷の残響 | 通常攻撃に氷の力が付く | 氷の敵から受けるダメージ −10% | 氷の敵 |
| 光の残響 | 通常攻撃に光の力が付く | 光の敵から受けるダメージ −10% | 光の敵 |
| 闇の残響 | 通常攻撃に闇の力が付く | 闇の敵から受けるダメージ −10% | 闇の敵 |
| 柔らかい残響 | 柔らかい敵へのダメージ +25% | 柔らかい敵から受けるダメージ −15% | 柔らかい体の敵 |
| 硬い残響 | 硬い敵へのダメージ +25% | 硬い敵から受けるダメージ −15% | 硬い体の敵 |
| 霊体の残響 | 霊体の敵へのダメージ +25% | 霊体の敵から受けるダメージ −15% | 霊体の敵 |
| ただの残響 | 攻撃力 +1 | 守り +1 | 無属性の敵・普通の体の敵 |
| ぬくもりの残響 | 満腹度の減りが10%遅くなる | 満腹度の減りが10%遅くなる | どの敵でも（落とすうちの2割） |
| 鼓動の残響 | 技ゲージが満タンになるまでの回数が1減る（2回より減らない） | 敵から攻撃を受けたとき、20%の確率で技ゲージ+1 | どの敵でも（落とすうちの2割） |

- 敵の属性と体質のどちらにも合う残響があるときは、半々で落とす。落とすうちの2割（設定で変えられる）は、ぬくもり・鼓動のどちらか。
- 同じ残響を複数のスロットにはめられる。効果は足し算（受けるダメージの軽減は、合計80%まで。満腹度の軽減は90%まで）。属性の付与は、いちばん先の1つだけ効く。
- 手に入れたときは、倉庫に直接入る。力尽きても、なくならない。

## 付け替え（忘れ物屋）

- 忘れ物屋に、**「刻印」の売り場（タブ）**を足す。持っている刻印装備を選び、スロットを押して、倉庫の残響をはめる・外す。
- 付け替えは、何度でも、無料。外した残響は倉庫に戻る。
- 刻印装備は、ふつうの武器・防具と同じ「装備する」で付けられる（装備枠は、武器1つ・防具1つのまま）。ふつうの武器・防具を選ぶと、刻印装備は外れる。
- 探索中は付け替えられない（準備の段階の決定にする）。

## 物語との関係

- 敵は、迷路に残った記憶の影。残響は、その名残。説明文は、短く、静かに書く。
- 物語の約束（`docs/story.md`）のとおり、感情は抽象的に書き、方法や場面には触れない。

## 作り方のメモ

- 設定：`src/game/echoes.json`（管理画面の「残響」タブ）。落とす確率・スロット数の割合・段階の範囲・残響ごとの効果の数字。
- セーブ：刻印装備の一覧（`engraved`：番号・元の品・スロット）と、倉庫の残響（`echoes`）。昔の記録は、空から始める。
- 探索：落とした分は探索のあいだ持っていて（`ExploreState.found`）、終わったとき（力尽きても、リタイアしても）倉庫に入る。
- 落とすくじは、探索の乱数を使わず、シードと行動の回数と敵の番号から決める（今までの探索の流れを変えない）。
