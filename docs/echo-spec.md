# 刻印武器と残響（設計。2026-11-19）

武器に、**刻印スロット**を付ける（防具にはない）。スロットにはめるアイテムの総称は**残響**。
どちらも買えない。敵が、ごく稀に落とす。今の「+の数が大きい品を買い替える」だけの強化に、選ぶ楽しみを足す。

数字は**管理画面の「残響」タブ**で変えられる（設定ファイルは `src/game/echoes.json`）。下の数字は、初期の値。

## 決まったこと（2026-11-19、ユーザーの選択）

| 項目 | 決めたこと |
|---|---|
| 総称 | **残響**（ざんきょう）。迷路が忘れた記憶の残り、という物語の言葉にする |
| 刻印スロット付きの武器 | **買えない**。敵がごく稀に落とす。店で買える+の付いた武器は、今のまま残す。**スロットがあるのは武器だけ**（2026-11-19、ユーザーの変更） |
| 残響の落とし方 | 敵の**属性・体質に合う**残響が落ちる（炎の敵→炎の残響、硬い敵→硬い残響）。どのダンジョンで集めるかが、準備の判断になる |
| 力尽きたとき | **失わない**。拾った残響と刻印武器は、そのまま倉庫に入る（リタイアも同じ） |
| 付け替え | **自由**。外した残響は倉庫に戻る。忘れ物屋の「刻印」の売り場で行う |
| 宝箱 | 宝箱からは**出ない**。敵が落とすだけ |
| 数字 | 管理画面で変えられる |

## 刻印武器

- **スロットがあるのは武器だけ**。防具にスロットはない（防具の属性の守りは、これから作る指輪が担う。`docs/ring-spec.md`）。
- **種類**：今の武器（剣・槌・杖）と同じ形で、刻印スロットが付いたもの。名前は「刻まれた」＋元の名前。
- **何が出るか**：倒した敵の体質に効く武器（柔らかい→剣、硬い→槌、霊体→杖、普通の体→どれか）。
- **強さ**：元の武器の段階は、設定の範囲（初期は2〜8段）からくじで決まる。強さの差は、スロットで出す。
- **スロット数**：1〜3個。出やすさは、初期は 1個90%・2個8%・3個2%。
- **落とす確率**（初期）：通常の敵0.3%・強敵3%・ボス10%。
- 倒したとき、その場で倉庫に入る（道具の枠は使わない）。同じ種類が何個でも持てる（スロットが違うので、別のもの）。

## 残響

敵が落とす確率（初期）：**通常の敵2%・強敵10%・ボス50%**。残響は、**武器のスロットにはめるものだけ**（防具や指輪にははめない）。

| 残響 | 武器にはめたときの効果（初期の数字） | 落とす敵 |
|---|---|---|
| 炎の残響 | 通常攻撃に炎の力が付く（砥石の力が先） | 炎の敵 |
| 氷の残響 | 通常攻撃に氷の力が付く | 氷の敵 |
| 光の残響 | 通常攻撃に光の力が付く | 光の敵 |
| 闇の残響 | 通常攻撃に闇の力が付く | 闇の敵 |
| 柔らかい残響 | 柔らかい敵へのダメージ +25% | 柔らかい体の敵 |
| 硬い残響 | 硬い敵へのダメージ +25% | 硬い体の敵 |
| 霊体の残響 | 霊体の敵へのダメージ +25% | 霊体の敵 |
| ただの残響 | 攻撃力 +1 | 無属性の敵・普通の体の敵 |
| 余韻の残響 | 通常攻撃のあと、同じ敵に、与えたダメージの25%の追加ダメージ（1より減らない。1回目で倒したら出ない） | 強敵・ボス |
| 寝息の残響 | 眠っている敵へのダメージ +50%（眠りの霧と組み合わせる） | 眠っているあいだに倒した敵 |
| 澱みの残響 | 通常攻撃が10%の確率で、敵の足元に毒の霧を残す（3ターン。1ターンのダメージは、当てたダメージの25%） | 毒の攻撃をする敵 |
| ためらいの残響 | 通常攻撃が10%の確率で、敵を1ターン動けなくする（ボスには効かない） | 突進してくる敵 |
| 分け合いの残響 | 通常攻撃で与えたダメージの5%だけ、HPが回復する（1より減らない） | 闇の敵 |
| ひそやかの残響 | まだ気付いていない敵に気付かれる距離が1マス縮む（1マスより縮まない。追ってくる敵の視界はそのまま） | 見張り（仲間を呼ぶ敵） |
| ささやきの残響 | 魔力 +1 | 遠くから撃ってくる敵 |
| 貫きの残響 | 盾に防がれる分が25%減る（4つで防がれない） | 盾持ち |
| 不意の残響 | 不意打ち（まだ気付いていない敵への通常攻撃）のダメージ +50% | 待ち伏せする敵 |
| 霜踏みの残響 | 敵の攻撃で鈍足になる確率が50%下がる（2つでならない） | 鈍足にしてくる敵 |
| 満ち足りの残響 | 敵を倒すと、満腹度が5戻る | 空腹にしてくる敵 |
| 残り火の残響 | 燃えている敵へのダメージ +30% | 炎の足跡を残す敵 |
| 絆の残響 | 敵を倒すと、次の通常攻撃のダメージ +25%（1回で消える） | 召喚する敵 |
| 背水の残響 | HPが半分以下のとき、通常攻撃の攻撃力 +3 | ボス |
| 吸魔の残響 | 敵を倒すと、魔力が2戻る | 魔法に弱い敵 |
| 追憶の残響 | 前の通常攻撃と同じ敵を殴ると、ダメージ +15% | 硬い敵 |
| ぬくもりの残響 | 満腹度の減りが10%遅くなる | どの敵でも（落とすうちの2割） |
| 鼓動の残響 | 技ゲージが満タンになるまでの回数が1減る（2回より減らない） | どの敵でも（落とすうちの2割） |
| 灯の残響 | 視界が1マス広がる | どの敵でも（落とすうちの2割） |
| 拾い癖の残響 | 敵が落とす忘れ物（お金）が15%増える（ボスの報酬も） | どの敵でも（落とすうちの2割） |
| 学びの残響 | 敵を倒したときの経験値 +20% | どの敵でも（落とすうちの2割） |

余韻〜ささやき・灯・拾い癖は、2026-11-23 に足した（ユーザーの選択）。貫き〜追憶・学びも、同じ日に足した（提案の10種類すべて。霜踏みは、敵が鈍足になる仕組みがないので「鈍足の敵へのダメージ増」はやめ、鈍足になりにくくなるだけにした）。倒したときの残響（満ち足り・吸魔・絆・学び）は、呪文などで倒したときも効く（呼ばれた敵とボスでは効かない）。おまけ（余韻・寝息・澱み・ためらい・分け合い）は、ふつうに殴ったときだけ効く（技・呪文には付かない）。澱み・ためらいの確率は、探索の乱数で引く（はめていなければ、引かない）。

- 落とすうちの2割（設定で変えられる）は、敵に関係なく、ぬくもり・鼓動・灯・拾い癖・学びのどれか（同じ割合）。
- 残りは、その敵に合う残響の候補から、同じ割合で1つ選ぶ。候補は、属性に合うもの・体質に合うもの（無属性・普通の体は、ただの残響）。そのうえで、闇の敵は分け合い、硬い敵は追憶、魔法に弱い敵は吸魔、毒の敵は澱み、突進する敵はためらい、見張りはひそやか、遠くから撃つ敵はささやき、盾持ちは貫き、待ち伏せする敵は不意、鈍足にしてくる敵は霜踏み、空腹にしてくる敵は満ち足り、炎の足跡を残す敵は残り火、召喚する敵は絆、強敵・ボスは余韻、ボスは背水、眠っているあいだに倒すと寝息も候補に入る。
- 同じ残響を複数のスロットにはめられる。効果は足し算（満腹度の軽減は90%まで）。属性の付与は、いちばん先の1つだけ効く。
- 手に入れたときは、倉庫に直接入る。力尽きても、なくならない。
- **ダンジョンごとの切り替え**（2026-11-23、ユーザーの要望）：ダンジョンの設定（管理画面の「敵の数と置き方」タブの「落とし物」）で、そのダンジョンの敵が残響を落とすか・刻印武器を落とすかを、それぞれオン・オフできる（`enemies.echoDrop`・`enemies.engravedDrop`）。オフでもくじは同じに引き、当たっても落とさない（指輪の落とし物は変わらない）。

## 付け替え（忘れ物屋）

- 忘れ物屋に、**「刻印」の売り場（タブ）**を足す。持っている刻印武器を選び、スロットを押して、倉庫の残響をはめる・外す。
- 付け替えは、何度でも、無料。外した残響は倉庫に戻る。
- 刻印武器は、ふつうの武器と同じ「装備する」で付けられる（武器の装備枠は1つのまま）。ふつうの武器を選ぶと、刻印武器は外れる。
- **サブ武器にもできる**（2026-11-23、ユーザーの要望）：刻印の売り場の「サブにする」で、持ち替えて使う2本目の武器にできる。ふつうのサブ武器と同じく、メインとちがう種類のときだけで、持っていける道具が1つ減る。メインと同じ刻印武器はサブにできない。サブの残響は、持ち替えて手に持ったときに効く（メインの残響は、そのあいだ効かない）。
  - サブにした刻印武器をメインにする・メインを同じ種類の武器に替えると、サブは外れる。ふつうの武器をサブにすると、刻印武器のサブは外れる。メインの刻印武器を外すと、サブも外れる。
  - セーブの持ち物に `weapon2Gear`（サブにした刻印武器の番号）、出発の情報と中断データに `subEchoes`（サブの残響）。
- 探索中は付け替えられない（準備の段階の決定にする）。

## 物語との関係

- 敵は、迷路に残った記憶の影。残響は、その名残。説明文は、短く、静かに書く。
- 物語の約束（`docs/story.md`）のとおり、感情は抽象的に書き、方法や場面には触れない。

## 作り方のメモ

- 設定：`src/game/echoes.json`（管理画面の「残響」タブ）。落とす確率・スロット数の割合・段階の範囲・残響ごとの効果の数字。
- セーブ：刻印武器の一覧（`engraved`：番号・元の品・スロット）と、倉庫の残響（`echoes`）。昔の記録は、空から始める。
- 探索：落とした分は探索のあいだ持っていて（`ExploreState.found`）、終わったとき（力尽きても、リタイアしても）倉庫に入る。
- 落とすくじは、探索の乱数を使わず、シードと行動の回数と敵の番号から決める（今までの探索の流れを変えない）。
