# ストーリー（確定版。2026-11-16）

この文書は、ストーリーそのものを決めたもの。**ゲームとの結びつけ（どこで、どう見せるか）は、まだ決めていない**（最後の「これから決めること」を参照）。実装もしていない。

決めた方針は、すべてユーザーが選んだもの。

| 決めたこと | 選んだもの |
|---|---|
| 「あの子」 | 子どもの頃の、自分自身 |
| 祠と、時を戻す力 | 祠は、心の中のトラウマ。時を戻す力は、自害と結びつける |
| ボス5体 | 苦い思い出（感情の形のまま。具体的な出来事は書かない） |
| 結末 | 一生救われないので、終わらない。ただし、記憶のかけらが、ほんの少しずつ増える |
| トーン | 静かで少し暗い。名前のない主人公（「あなた」）。スマホで短く読める文章 |
| 現在のあなた | 部屋に引きこもっている。「また、終わらせようか」と、いつも考えている |
| 部屋の場面を出すところ | 記憶を取り戻したときと、最後の場面だけ |
| かけらの中身 | ささやかなもの |
| 注意書き | 入れる |

## 物語の芯

- **あなた**は、大人のいまの自分。カーテンの閉まった部屋に引きこもり、「また、終わらせようか」と、毎朝のように考えている。
- **あの子**は、子どもの頃のあなた。あなたは、あの頃の自分を救うために、時を戻したいと願い続けてきた。
- **祠**は、あなたの心の中にあるトラウマ。ダンジョンは、忘れたはずの記憶の迷宮。
- **時が戻る**のは、祠の中で力尽きたとき。力尽きるたびに、あの朝に戻され、記憶も薄れる。薄れることが、あなたにとっての逃げ場になっている。ただし、本当の過去は変わらない。
- **ボス5体**は、5つの苦い思い出。倒すと、その記憶が戻る。
- **結末**：5つ全部を思い出し、「あの子は、あなた自身だった」と分かっても、何も解決しない。灯を消せば、また朝が来る。物語は終わらず、記憶のかけらだけが、ほんの少しずつ増えていく。

## 表現の約束

- 自害は、場面を描かず、方法にも触れず、肯定しない。「また、終わらせようか」のような、ほのめかしだけにする。
- 苦い思い出は、感情の形（怒り・孤立・自責・裏切られた期待・消えたい願い）にとどめ、家庭の事情などの具体的な出来事は書かない。
- 救われない物語だが、ささやかな変化（かけら）を必ず残す。
- 遊び始める前に、注意書きを出す（下の文面）。

## 5つの記憶

ボスは潜るたびに属性で変わるので、記憶は**順不同**。どれから思い出しても成り立つようにする。どの記憶も、あとに「倒したボスの一文」を添える。

| 記憶 | ボス | 文章 |
|---|---|---|
| 怒りと恐れ | 炎の魔獣 | 大きな声が、家をゆらしていた。／あの子は、布団の中で息をひそめた。／誰も来ない。耳をふさいでも、声は入ってきた。<br>**ボスの一文**：炎の魔獣が崩れた。焦げた匂いだけが、あの夜と同じだった。 |
| 孤立 | 氷の巨像 | 呼んでも、振り向く人はいなかった。／あの子は、笑うのをやめた。／冷たいのは、外ではなかった。<br>**ボスの一文**：氷の巨像が砕けた。冷たい指先の感触だけが、手に残った。 |
| 自責 | 鬼の首領 | うまくできない自分が悪いのだと、あの子は思った。／責める声は、いつのまにか、自分の声になっていた。<br>**ボスの一文**：鬼の首領が膝をついた。誰かを責めた声が、自分のものだと気づく。 |
| 裏切られた期待 | 光の守護者 | 「きっと大丈夫」と、誰かが言った。／あの子は、それを信じた。／大丈夫では、なかった。<br>**ボスの一文**：光の守護者が消えた。まぶしさの向こうに、小さな背中が見えた気がした。 |
| 消えたい願い | 闇の王 | 消えてしまいたい、と、はじめて思った夜。／あの子は、まだ小さかった。／その願いだけが、いまも、あなたの中にある。<br>**ボスの一文**：闇の王が溶けた。暗がりが、少しだけ、やさしかった。 |

## 部屋の場面

記憶を取り戻したときの、記憶の前に1〜2行だけ出す。最初は、こう。

> カーテンの閉まった部屋。何日も、同じ天井を見ている。
> 「また、終わらせようか」

2回目以降は、同じ部屋の、ほんの少しの変化を足す（案。順に使う）。

1. 今朝は、窓の外の音が、少し聞こえた。
2. カーテンのすきまから、光が細く入っていた。
3. 机の上のコップに、水が入っていた。
4. 誰かの足音が、廊下を通りすぎた。

## 5つそろったとき（最後の場面）

> あの子の顔を、ようやく思い出す。
> それは、鏡の中のあなたに、よく似ていた。
> あの子は、あなた自身だった。
> 救いたかったのは、いつも、あの頃の自分だった。
> けれど、時は戻らない。
> 灯を消せば、また朝が来る。

この場面の前にも、部屋の場面を出す。

## 終わらない朝（かけら）

5つそろったあとも、ゲームは続く。ボスを倒すたびに、部屋の場面と、あの子のかけらが1つ出る（案）。かけらは、ささやかなもの。

1. あの子は、雪が好きだった。
2. あの子は、あたたかいミルクを、両手で持つのが好きだった。
3. あの子は、帰り道で、猫にあいさつをしていた。
4. あの子は、鼻歌をうたうとき、いつも同じところで間違えた。
5. あの子は、星の名前を、ひとつだけ知っていた。
6. あの子は、いつか大きくなったら、遠くへ行きたいと言っていた。
7. あの子は、誰かの「ありがとう」が、うれしかった。
8. あの子は、ほんとうは、笑うのが好きだった。

使い切ったあとは、最後のかけらを繰り返す（案）。解決には至らない。

## これから決めること（ゲームとの結びつけ）

- **ボスの順番と運**：記憶はボスに結びつくので、5体すべてを倒すまでに、運による遠回りが出る。どう扱うか（ダンジョンの属性を選べるようにする、同じボスの記憶は別の言い方で重ねる、など）。
- **部屋の場面と記憶の画面**：どの画面で、どんな見せ方にするか（暗い画面に、1行ずつ静かに浮かび上がる、など）。
- **力尽きたとき**：結果の画面に、時が巻き戻る一文を出すか。出すなら、文面と、自害のほのめかしとの距離。
- **すでに取り戻した記憶のボスを倒したとき**：5つそろう前は、何を出すか（出さない、部屋の場面だけ、など）。
- **注意書き**：初回だけか、設定からいつでも読めるようにするか。
- **見た目**：ダンジョンの空気（色・音）を、物語に合わせて変えるか。
