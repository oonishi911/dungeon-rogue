# ストーリー（2026-11-16）

ゲームに物語を付ける。方針は、次の4つの選択で決めた（すべてユーザーが選んだもの）。

| 決めたこと | 選んだもの |
|---|---|
| 物語のおおもと | 失われた記憶を探す |
| 力尽きても、また最初から潜れる理由 | 時が巻き戻る |
| 物語の見せ方 | ボスを倒した直後に、フラッシュバックのように、過去の記憶が少しずつよみがえる |
| トーンと主人公 | 静かで少し暗い。名前のない主人公（「あなた」）。スマホで短く読める文章 |

実装は `src/game/story.ts`（文章とルール）、`src/ui/MemoryScreen.tsx`（画面）。文章はすべて `story.ts` にあり、ここを書き換えれば変えられる（管理画面からは変えられない）。

## 物語のあらすじ

- 村のはずれの祠には、「奥に灯のともる夜、時は一度だけ戻る」といういいつたえがある。
- あなたには、大切な子がいた（名前も顔も、まだ思い出せない。「あの子」と呼ぶ）。あの子は冬に熱を出して眠ったまま、目を開けなかった。あなたは雪の夜に祠へ行き、「あの子の冬を、もう一度」と願った。
- 祠は答えた。「時を戻そう。ただし、戻すたびに、あなたの記憶を灯の油にする」。あなたはうなずいた。
- それから何度も、力尽きるたびに時が戻り、戻るたびに記憶を失った。いまのあなたは、何も覚えていない。
- ゲームの中では、祠が入るたびに別の力（炎・氷・光・闇・無属性）に染まるのは、祠が「灯の油」として貯めた記憶が、ボスの姿に変わっているため。ボスを倒すと、その記憶が戻る。
- 5つめの記憶で、あなたは気づく。ここへ来るのは、思い出すためではなく、灯を持ち帰るためだった。灯を抱えて外へ出ると、朝になっていて、あの子の声がする。物語はここで終わるが、祠はまだ待っている（そのあとも、同じように遊べる）。

## 仕組み（`story.ts`）

- 記憶は5つ（`STORY_CONFIG.memories`）。ボスを倒して踏破するたびに、1つめから順に1つずつよみがえる。**どのボスを倒しても、同じ順番**（ダンジョンの属性が潜るたびに変わるので、ボスの種類で順番を変えると、遠回りが出るため）。
- 倒したボスごとに、記憶のあとに一文を添える（`BOSS_ECHOES`。5体とも）。
- 5つめの記憶のあとには、物語の終わり（`ENDING`）が続く。6回目以降の踏破では、記憶の画面は出ない。
- 力尽きたとき・リタイアしたときは、結果の画面に「時が巻き戻る」一文を出す（`REWIND_LINES`。挑戦の回数で順に入れ替える）。
- よみがえった記憶の数は、セーブデータの `memories`（0〜5）に残る。記録のない昔のデータは0から。

## 画面

- ボスを倒した直後（ダンジョンの踏破の直後）：結果の画面の前に、記憶の画面が1つ出る。文章は1行ずつ静かに浮かび上がる（「動きを減らす」設定では、すぐ全部出る）。「結果を見る」で、結果の画面へ進む。
- ダンジョンを選ぶ画面：記憶が1つ以上あれば、「思い出した記憶を読む（○／5）」のボタンが出る。一覧から、よみがえった記憶をもう一度読める（まだの記憶は「まだ思い出せない」）。
- 結果の画面（力尽きた・リタイアのとき）：題の下に、時が巻き戻る一文が出る。

## 文章（そのまま `story.ts` にある。直すときはここも直す）

1. **冬の朝**：小さな手が、あなたの袖をつかんでいた。／「あした、祠の灯を見にいこうね」／声だけが、はっきり残っている。／顔は、まだ思い出せない。
2. **祠のいいつたえ**：村のはずれの祠には、いいつたえがあった。／奥に灯のともる夜、時は一度だけ戻る。／大人たちは、笑い話にした。／あなたも、そうだった。あの冬までは。
3. **眠ったままの子**：あの子は、熱を出して眠ったまま、目を開けなかった。／医者は、静かに首を振った。／雪の降る夜、あなたはひとりで家を出た。／祠へ向かう道は、足跡ひとつなかった。
4. **祠との約束**：「あの子の冬を、もう一度」／祠は答えた。時を戻そう、と。／「ただし、戻すたびに、あなたの記憶を灯の油にする」／あなたは、うなずいた。うなずいてしまった。
5. **灯**：何度目の朝か、もう数えられない。／力尽きるたびに戻り、戻るたびに、忘れていった。／それでも足は、この奥へ向かっていた。／思い出すためではない。／灯を、持ち帰るためだ。

## まだ入れていないもの（あとで足せる）

- ゲームを始めたときの短いプロローグ（目覚めの場面）。いまは、最初のボスを倒すまで物語は何も出ない。
- 情報屋や店主が、物語について話すこと（情報屋は、主人公の事情を知っているかもしれない、など）。
- 探索中に拾える手記。
- 物語が終わったあとの変化（6回目以降の踏破で、別の短い場面を出す、など）。
